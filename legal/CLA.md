## Propósito

O Olivas Power System Studio adota **dual licensing**:

- **Edição Community** distribuída sob **Apache License 2.0**;
- **Edição Pro** distribuída sob **EULA proprietária**.

Para que o Licenciante (Landerson Ferreira Silva / CNPJ ME a
constituir) possa **continuar oferecendo a edição Pro sob
licença proprietária** mesmo recebendo contribuições externas
sob Apache 2.0, **todo contribuidor externo** deve assinar
este CLA antes que seu primeiro Pull Request seja mesclado.

Isso é juridicamente necessário porque, sem cessão de direitos,
contribuições aceitas no repositório Apache 2.0 não poderiam
ser redistribuídas pelo Licenciante sob outra licença
(proprietária) sem violar o copyright do contribuidor.

## Definições

- **Contribuidor**: pessoa física ou jurídica que submete
  Pull Request, Issue com código, patch, documentação ou
  qualquer obra ao repositório oficial.
- **Contribuição**: qualquer obra de autoria do Contribuidor
  intencionalmente submetida ao repositório oficial.
- **Licenciante**: Landerson Ferreira Silva / CNPJ ME a
  constituir, detentor do projeto Olivas Power System Studio.

## 6. Como aceitar este CLA

### Pessoa física (Individual)

Adicione o seguinte no rodapé do **primeiro commit** do seu PR:

```
Signed-off-by: Seu Nome <seu-email@example.com>
CLA-Accepted: 1.0.0
```

A simples submissão do PR com essa assinatura constitui
aceite eletrônico, conforme **Art. 10, §2º, MP 2.200-2/2001**.

### Pessoa jurídica (Corporate)

Empresas devem enviar **CLA assinado em papel ou via assinatura
digital ICP-Brasil** para `cla@olivas.com.br` (a configurar),
declarando os funcionários autorizados a contribuir.

## 7. Vigência

7.1. Este CLA é **perpétuo** quanto às licenças concedidas e
**vincula** o Contribuidor a partir do primeiro aceite, para
todas as Contribuições posteriores.

7.2. O Contribuidor pode **revogar futuras contribuições**
notificando o Licenciante, mas **não pode revogar** licenças
sobre Contribuições já aceitas.
