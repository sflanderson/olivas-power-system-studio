## 5. Smoke Test Manual

### 5.1 Inserir Link Tag
> 1. Right-click em área vazia do canvas
> 2. Submenu: "🔗 Inserir Link Tag..."
> 3. Dialog 1: "Texto exibido na tag" (default "Ver TCC-A")
> 4. Dialog 2: "Target" (default "tcc:CoordA")
> 5. OK → Link Tag aparece no canvas
> 6. Click no Tag → MainWindow abre TCC coordinogram

### 5.2 Inserir Legend Tag
> 1. Right-click → submenu "⬥ Inserir Legend Tag" → escolher shape
> 2. Dialog: "Texto interno" (default "Z-DIA")
> 3. OK → Legend Tag aparece com forma e cor amarela PTW

### 5.3 Auto-bus-node em série
> 1. Tem um wire entre 2 BUSes
> 2. Drag-drop um R (resistor) da paleta sobre o wire
> 3. Wire some, R aparece no ponto, 2 wires substituem o original
> 4. Ctrl+Z desfaz tudo de uma vez

### 5.4 Auto sidecar
> 1. Adicionar Link Tag ou Legend Tag ao projeto
> 2. Salvar como `meu.sch` (Ctrl+S)
> 3. Arquivo `meu.olivas.json` é criado automaticamente
> 4. Reabrir `meu.sch` → tags são recarregadas automaticamente

## 6. Anti-alucinação — limitações declaradas

1. **Multi-document navigation deferred v3.2.0+** — `oneline:DocName`
   apenas mostra status msg, não abre tab de outro documento.

2. **AddLinkTag dialog é simplista** — apenas 2 QInputDialogs (label + target).
   v3.2.0 pode ter dialog completo com browser de targets, color picker para
   `closed_arrow`, etc.

3. **`AddLegendTag` não permite editar cor pelo dialog** — apenas shape via
   submenu. Edição de cor via property panel deferred.

4. **`_find_wire_at` é simples bbox lookup**, não detecção exata de
   intersecção com path do wire L-routed. Para wires diagonais ou long
   `tolerance=8.0` pode dar falso positivo.
