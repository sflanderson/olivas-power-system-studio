## 3. Sprint A — Core ANSI C37 ✅ (20 testes verdes)

**NEW** `app/standards/ansi_c37.py` (~290 LOC, stdlib-only — `math`, `enum`):

### 3.1 MachineKind — Tabela §1.2.5 p. 1-8 (Xd"/Xd' multipliers)

7 categorias canônicas com tupla `(lv, first, interrupting)`:

| Tipo | LV | First | Interrupting |
|------|----|----|--------------|
| `TURBINE_GEN` | 1.0 | 1.0 | 1.0 |
| `HYDRO_NO_AMORTISSEUR` | 0.75 | 0.75 | 0.75 |
| `SYNCHRONOUS_MOTOR` | 1.0 | 1.0 | **1.5** |
| `INDUCTION_1000HP_LARGE` | 1.0 | 1.0 | 1.5 |
| `INDUCTION_250HP_MEDIUM` | 1.0 | 1.2 | 3.0 |
| `INDUCTION_50HP_LARGE` | 1.0 | 1.2 | 3.0 |
| `INDUCTION_BELOW_50HP` | 1.0 | **∞** | **∞** |

`math.inf` ≡ "neglect" (PTW notation).

### 3.2 is_local_to_fault — §1.2.4 p. 1-7 / §1.4.3 p. 1-36

```python
ratio = z_external_pu / xd_pu
return ratio < 1.5  # com tolerância FP (math.isclose) para borderline
```

LOCAL ⇔ ratio < 1.5; REMOTE ⇔ ratio ≥ 1.5 (default ANSI threshold).

### 3.3 separately_derived_xr — §1.2.3 p. 1-6

Fórmula PTW canônica (não usar X/R do equivalente Thévenin):

```
X_eq = (Σ 1/Xᵢ)⁻¹     R_eq = (Σ 1/Rᵢ)⁻¹     (X/R)_sep = X_eq / R_eq
```

Validado contra dois branches paralelos com R/X dispares.

### 3.4 momentary_rms_multiplier / momentary_peak_multiplier — §1.3.6 p. 1-17 (Eq. 7-1)

```
I_mom_rms / I_sym  = √(1 + 2·e^(-4πc/(X/R)))
I_mom_peak / I_sym = √2 · (1 + e^(-2πc/(X/R)))
```

Com c = 0.5 ciclos (half-cycle, ANSI canonical).
Para X/R = 25: rms ≈ 1.60, peak ≈ 2.66 — bate com simplificações
do manual (1.6 e 2.7 respectivamente).

### 3.5 lv_duty_adjusted — §1.2.3 p. 1-6

LV adjustment (boost/atenuação por (X/R)_sys vs (X/R)_test):

```
I_LVF = I_sym × √(1 + e^(-π/(X/R)_sys)) / √(1 + e^(-π/(X/R)_test))
```

Quando system_xr == test_xr → multiplier = 1 (idempotente, validado).

### 3.6 DeviceClass — §1.2.3 p. 1-5/1-6 (Test PF / Test X/R catalog)

| Device | Test PF | Test X/R |
|--------|---------|----------|
| `LV_PCB` | 0.15 | **6.6** |
| `LV_FUSE` | 0.20 | 4.9 |
| `MCCB_GT_20KA` | 0.20 | **4.9** |
| `MCCB_10_20KA` | 0.30 | 3.18 |
| `MCCB_LT_10KA` | 0.50 | **1.7** |
| `HV_FUSE` | 0.15 | 6.6 |

API: `get_test_xr(device)`, `get_test_pf(device)`, `get_asym_withstand(device)`.

## 5. 10 Oportunidades de SUPERAÇÃO identificadas

1. **API Pythonica embutível** — Olivas expõe `from app.standards.ansi_c37
   import machine_multiplier`; PTW só via GUI.
2. **Citation inline** — toda função tem docstring com `§x.y p. 1-z`;
   PTW manual é externo.
3. **Test-driven anti-alucinação** — 20 testes pareados com fórmula;
   PTW não disponibiliza suite reproduzível.
4. **Threshold configurável** — `is_local_to_fault(threshold=1.5)`
   permite estudo paramétrico de sensibilidade; PTW hardcoded.
5. **`math.inf` para "neglect"** — explícito Pythonico (vs. flag boolean
   ou número mágico no PTW).
6. **Stdlib-only core** — sem dependência de NumPy ou external lib;
   reduz superfície de ataque + portabilidade.
7. **Docstrings com LaTeX rendering** — Sphinx-ready math; PTW só
   PDF estático.
8. **Composição com IEC 60909** — mesma sessão pode rodar ANSI + IEC
   side-by-side; PTW exige projetos separados.
9. **CRDT-ready** — fórmulas funcionais puras → safe para sync
   multi-user (foundation v3.0.0).
10. **OSS auditável** — código verificável vs PTW closed-source.

## 9. Anti-alucinação — limitações declaradas

* **Manual auditado é 2006-03-26** (PTW pré-V11). Tabelas de
  Interrupting MF para breakers modernos (≥ 2010) podem diferir
  em fração — recomendado complementar com C37.010-2016 IEEE em
  release futura.
* **Tabela `_DEVICE_TEST_TABLE`**: o valor `MCCB_LT_10KA = 1.7` é o
  rounded canônico do manual (raw `tan(arccos(0.50)) = 1.732`).
  PTW arredondou para 1.7 nas suas tabelas de catalog — replicado
  para paridade exata.
* **Cases §1.4.1 não replicados** (Sprint D) — validação numérica
  contra os exemplos publicados ainda pendente; valida fórmulas
  sintéticas mas não reproduz exemplos reais do manual.
* **30-cycle network**: deferred Sprint C — fórmulas extraídas
  mas não codificadas.
