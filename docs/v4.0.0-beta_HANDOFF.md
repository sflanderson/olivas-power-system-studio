## 7. Anti-alucinação — limitações declaradas (beta)

1. **Beta NÃO production-ready ainda** — embora UAT prep concluído,
   release final v4.0.0 requer:
   - Performance profiling em projetos grandes
   - PyInstaller distribution test
   - User feedback loop
   - Localized documentation (manual em PT/EN/ES)

2. **i18n cobre GUI mas não documentação** — README.md ainda em PT;
   docs/ majoritariamente PT. Tradução completa deferred.

3. **Sem load testing** — sweep é unit/integration, mas não há
   benchmark de tempo real com projeto de 100+ buses.

4. **Sem mutation testing** — tests passam mas não há verificação
   formal de "kill ratio" via `mutmut` ou similar.
