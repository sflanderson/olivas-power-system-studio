## 1. Handoff Spec — BREAKER & RELAY topology

### Problema (root cause)

**BREAKER**:
- YAML (`BREAKER.ocomp`) sempre teve 3 pinos: T1, T2, Trip_in
- Renderer (`CircuitBreakerSymbol.PINS`) tinha apenas **2 pinos
  verticais** ((0,-30), (0,30))
- **Inconsistência**: usuário via 2 pinos no canvas (no Trip_in)
  apesar do spec definir 3
- Solution: alinhar PINS do renderer com YAML → 3 pinos

**RELAY**:
- YAML tinha 4 pinos: T1, T2, TC_link, Trip_out
- T1/T2 ("Linha entrada/saída") sugeriam que relé conecta à barra
- Errado conceitualmente: relé de proteção real (IED) **não
  conduz corrente principal**; só recebe medição via TC e
  envia trip via contato seco para BREAKER
- Solution: remover T1/T2 do YAML + renderer → 2 pinos

### Topology corrigida

```
[BUS] ── T1.BREAKER ─── T2.BREAKER ── P1.CT ── P2.CT ── [MOTOR]
              │
              Trip_in ←── Trip_out.RELAY ←── TC_link.RELAY ←── S1.CT
              (laranja)    (laranja)         (verde)            (verde)
```

**RELAY agora** tem apenas 2 conexões:
1. `TC_link` (topo) — vem de `CT.S1` (medição secundária)
2. `Trip_out` (baixo) — vai para `BREAKER.Trip_in` (proteção)

**RELAY NÃO conecta à barra** — paridade com IED real.

### Components atualizados

| Component | Pinos antes | Pinos depois | Mudança |
|-----------|-------------|--------------|---------|
| `BREAKER` (renderer) | 2 (top, bottom) | **3** (T1 esq, T2 dir, Trip_in topo) | + Trip_in |
| `BREAKER` (YAML) | 3 (já tinha) | 3 (sem mudança) | aligned |
| `RELAY` (renderer) | 4 (T1, T2, TC_link, Trip_out) | **2** (TC_link topo, Trip_out baixo) | − T1, T2 |
| `RELAY` (YAML) | 4 | **2** | − T1, T2 |

### Design tokens (mantidos de v2.0.2)

| Pin Categoria | Cor | Aplicação no BREAKER/RELAY |
|---------------|-----|---------------------------|
| 🔵 POWER | `#1976D2` | BREAKER.T1, BREAKER.T2 |
| 🟢 SIGNAL | `#2E7D32` | RELAY.TC_link |
| 🟠 TRIP | `#E65100` | BREAKER.Trip_in, RELAY.Trip_out |

Cores agora **casam visualmente** entre componentes conectados:
* BUS power chain: tudo azul
* CT secondary signal: verde→verde (CT.S1 → RELAY.TC_link)
* Trip wire: laranja→laranja (RELAY.Trip_out → BREAKER.Trip_in)

### States and Interactions (mantidas)

| Element | State | Behavior |
|---------|-------|----------|
| BREAKER pin Trip_in | Selected | Ring azul + label "Trip_in" visível |
| RELAY pin TC_link | Selected | Ring azul + label "TC_link" visível |
| RELAY paint | Default | Círculo R sem leads laterais (símbolo limpo) |
| BREAKER paint | Default | Quadrado com cruz + 3 leads (esq, dir, topo) |

### Edge Cases

| Caso | Comportamento |
|------|---------------|
| .sch antigo com RELAY tendo T1/T2 wired | Wires ficam orphan (apontando para coordenadas que não existem mais como pinos) — usuário precisa religar para TC_link/Trip_out |
| Examples/templates legacy | Não há templates RELAY com T1/T2 wired no codebase atual |
| Tests v1.4.x | test_RELAY_spec_loadable só verifica properties (não conta pinos) → continua passando |

### Anti-perda confirmado

* **Modificações cirúrgicas**:
  * `ptw_symbols.py::CircuitBreakerSymbol` — PINS 2→3 + paint
  * `ptw_symbols.py::RelaySymbol` — PINS 4→2 + paint
  * `RELAY.ocomp` — 2 pinos T1/T2 removidos do YAML
* **NÃO tocados**:
  * BREAKER.ocomp (já estava correto)
  * Outros 54 specs YAML
  * Lista TRAVADA (arc-flash, CT-SAT, DAPPER, plugins)
