## 7. Anti-alucinação — limitações declaradas

1. **MF formulas analíticas vs gráficos**: as Figs 1-1..1-15 são gráficos
   fotograficamente interpolados (§1.3.8 linhas 1267-1273). Olivas usa
   fórmulas analíticas (Eq. 7-1 com c=t_cp + AC decrement parametrized)
   com tolerância ±5-10% vs valores publicados. Para precisão ±1%,
   recomenda-se substituir por dataset numérico de IEEE Std 551-2006.

2. **§1.5 não existe**: o manual A_Fault termina em §1.4.4. Asym Withstand
   está em §1.2.3 (já explorado em v3.0.2 + estendido em v3.0.3 B.7).

3. **NACD ratio "não-oficial em ANSI"**: o modo INTERPOLATED é interpretação
   técnica padrão, mas o manual declara explicitamente (§1.3.3 linhas 632-635)
   que **não é oficialmente reconhecido pelos ANSI C37 Standards**. Olivas
   expõe com banner técnico no docstring.

4. **Manual auditado é 2006-03-26** (PTW pré-V11). Pós-2019 features
   ausentes — recomendado complementar com `PTW Version 11 Enhancements.pdf`.
