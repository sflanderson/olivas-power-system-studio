## 2. Escopo v2.0.0 (4 features grandes)

### 2.1 Live SCADA IEC 61850

**O que é**: comunicação real-time com SCADA de subestações via
protocolo IEC 61850-8-1 (MMS). Permite Olivas:

* Receber medições live (V, I, P, Q) de IEDs (Intelligent Electronic
  Devices)
* Comparar valores real-time vs cálculo Olivas
* Detectar discrepâncias → alertar engenheiro

**Anti-alucinação**: IEC 61850 é protocolo complexo (>1000 pp.
spec). v2.0.0 entrega **stub funcional** + **interface client**
que pode ser conectada a libs como `libiec61850` (C library com
Python bindings) em deploy real.

Escopo travado v2.0.0:
* `app/integration/iec61850_client.py` — Python interface
* `IEC61850MMSClient` dataclass (configuração)
* `MMSReport` dataclass (medição recebida)
* Stub mode (gera dados sintéticos para demo)
* Real mode (interface para libiec61850 — não roda sem lib)

**Não entrega**: deployment com IED real, GOOSE messaging,
SV (sample values).

### 2.2 Docker reproducibility

**O que é**: container Docker para reprodução determinística do
ambiente Olivas — qualquer engenheiro pode rodar o mesmo Olivas
em qualquer máquina, idêntica versão Python + deps.

Escopo:
* `Dockerfile` (Python 3.11 slim + dependencies)
* `docker-compose.yml` (Olivas + opcional postgres para multi-user)
* `docker/entrypoint.sh` (auto-detecta GUI vs headless mode)
* `docs/DOCKER.md` (guia uso)

**Anti-perda**: container roda Olivas em modo headless (sem GUI);
GUI continua funcionando localmente sem Docker.

### 2.3 i18n (PT/EN/ES)

**O que é**: traduções de strings de UI para Português (default),
Inglês, Espanhol. Suporta usuários LATAM + global.

Escopo:
* `app/i18n/__init__.py` — translation function `_()`
* `app/i18n/translations/pt.json` (default ~150 strings)
* `app/i18n/translations/en.json`
* `app/i18n/translations/es.json`
* `app/core/locale.py` — detect locale + fallback PT
* Não traduz cobertura completa de UI (escopo: principais menus
  + dialogs); v2.1+ amplia

**Anti-perda**: UI atual em PT continua funcionando; traduções
são **opt-in** via `set_locale("en")`.

### 2.4 Commercial launch prep

**O que é**: license keys + telemetry opt-in.

Escopo:
* `app/commercial/license_key.py` — validação de chave
  (ex: HMAC-SHA256, expiração, machine-bound opcional)
* `app/commercial/telemetry.py` — opt-in only, anonymous usage
  counting (`opens_per_week`, `studies_run`, etc)
* Settings dialog: "Configuração de licença"
* Default behaviour: educational (sem chave necessária); chave
  habilita features comerciais (export para PDF profissional,
  etc)

**Anti-alucinação**: nenhuma feature core do Olivas é gated
atrás de license key — é **opt-in para comercial**, não
**block para educational**.
