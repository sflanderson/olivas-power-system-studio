## 3. Decisões de design baseadas em PTW manuals

**Padrão 1 (Userguide §4)**: PTW nunca usa rótulos "Load External X".
Toda integração é interna ao `*.PRJ` via "Go to X". Por isso renomeamos
"Carregar JSON (PTW)" → "Importar dados de TCs (JSON)" + tooltip
explicativo de compatibilidade.

**Padrão 2 (CAPTOR §1.4.6)**: PTW usa **viewport único com aspect ratio
toggleable**. Subplots empilhados são raros; quando inevitáveis, usar
títulos no eixo Y, não ax.set_title (que sobrepõe). Aplicamos
`constrained_layout=True` + ylabel multilinha em N3.

**Padrão 3 (Equip Eval §1.2 + Coord Eval §3.4)**: análise é **disponível
apenas quando o componente está selecionado**. Itens acinzentados com
tooltip "Available only when X is selected". Replicamos com QMessageBox
de gating + escape hatch "modo didático".

**Padrão 4 (Datablock Reports, Userguide §6314)**: views vazias **mostram
texto explicativo** com instrução de como popular. Implementamos
`QStackedWidget` com page 0 = empty state QLabel + page 1 = matplotlib
canvas.
