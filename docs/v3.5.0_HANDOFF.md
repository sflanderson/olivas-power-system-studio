## 8. Anti-alucinação — limitações declaradas

1. **Scenario diff é shallow** — só compara componentes por name + type +
   #properties + valor das primeiras N props. Não detecta wires/datablocks
   modificados. v3.5.x adicionará deep diff.

2. **promote UNMODIFIED_ONLY é heurístico** — adiciona componentes novos
   do scenario à base; não detecta conflitos de campo. Real merge
   3-way deferred v3.5.x.

3. **Scenarios não persistem em disco** — manager é per-sessão. Save/load
   `.olivas-scenarios.json` deferred (mas pode reusar sidecar_io infra
   da v3.1.2).

4. **CRDT não está integrado** — scenarios + CRDT são paradigmas
   complementares (PTW vs Olivas-only) mas não composicionais por ora.
