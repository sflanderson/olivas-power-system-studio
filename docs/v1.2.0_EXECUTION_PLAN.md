## Faseamento

### Fase α (alpha) — Foundation: 17 TCC Segment Types

#### α.1 — Foundation (4 segments fundacionais)
**Escopo**: protocolo `TCCSegment` + segments básicos (LT, ST, INST, DefiniteTime)

| Segment | Família | Norma base |
|---|---|---|
| `TCCSegmentLT` | Pickup | IEC 60255 / ANSI C37.112 (extensão dos curve_types existentes) |
| `TCCSegmentST` | Pickup | IEC 60255 (Short Time element) |
| `TCCSegmentINST` | Pickup | IEEE C37.2 dev 50 |
| `TCCSegmentDefiniteTime` | Definite | IEC 60255 (definite-time element) |

**Aceite α.1**:
- Protocolo `TCCSegment` em `app/postprocessor/tcc_segments.py`
- 4 segments implementados como dataclass frozen
- 16+ testes (4 por segment) em `tests/test_pp_v1_2_0_tcc_segments_alpha1.py`
- Smoke test composição (LT + INST num mesmo plot)
- 100% verde

#### α.2 — Tolerance + I²T + Time-Current Points (4 segments)
**Escopo**: segments com bands/tolerância + curvas tabuladas

| Segment | Família | Norma base |
|---|---|---|
| `TCCSegmentAdjustableTolerance` | Pickup±band | PTW Adjustable Tolerance (±%) |
| `TCCSegmentI2T` | Definite/I²t | IEC 60255 (I²t element) |
| `TCCSegmentTimeCurrentPoints` | Custom | Interpolação log-log tabelada (datasheet) |
| `TCCSegmentFixTimeHorizontal` | Definite | PTW Fix Time Horizontal |

**Aceite α.2**: 16+ testes, 100% verde.

#### α.3 — Analytic formulas (PTW exclusive — 2 segments)
**Escopo**: as 2 fórmulas analíticas paramétricas do CAPTOR

| Segment | Fórmula |
|---|---|
| `TCCSegmentAnalyticAD` | `T = AD/((I/Ipu)^N - C) + BD + K` |
| `TCCSegmentAnalyticSM` | `T = SM·[A + B(I/Ipu - C) + D/(I/Ipu - C)^2 + E/(I/Ipu - C)^3]` |

**Aceite α.3**: 12+ testes (parâmetros válidos + edge cases I→pickup), 100% verde.

#### α.4 — Breaker curves (4 segments)
**Escopo**: curvas de disjuntor (opening + clearing + bands)

| Segment | Família |
|---|---|
| `TCCSegmentOpening` | Breaker (opening time only) |
| `TCCSegmentClearing` | Breaker (opening + arcing) |
| `TCCSegmentOpenClearCurve` | Envelope min/max |
| `TCCSegmentOpenClearBand` | Banda entre 2 envelopes |

**Aceite α.4**: 16+ testes, 100% verde.

#### α.5 — Slope-T + Delay Band (2 segments)
**Escopo**: o I^Slope-T e Delay Band

| Segment | Fórmula |
|---|---|
| `TCCSegmentSlopeT` | `T = K · (I/Ipu)^slope` (PTW Delay Band) |
| `TCCSegmentDelayBand` | Banda min/max + slope |

**Aceite α.5**: 8+ testes, 100% verde.

**Total α**: ~16 segments, ~70 testes, ~3000 LOC.

### Fase β (beta) — Multi-Function Device

#### β.1 — `TCCDevice` dataclass com lista de segments
- Cada device tem `device_id` + `manufacturer` + lista de `TCCSegment`
- Método `composite_envelope(I)` retorna `min(t_segment)` para todos enabled

#### β.2 — `MultiFunctionRelay` (subclasse de TCCDevice)
- Helpers para padrões comuns:
  - `IDMT_only(curve_type, pickup, tms)` → 1 segment LT
  - `IDMT_with_50(curve_type, pickup_51, tms, pickup_50, delay_50)` → 2 segments
  - `IDMT_with_50_and_49(...)` → 3 segments
  - `with_87_diff(...)` → +1 segment

#### β.3 — Coordination check com devices
- `check_device_coordination(upstream_device, downstream_device, fault_A)` retorna pior caso entre todos os pares de segments

**Aceite β**: 30+ testes, smoke test com SEL-751 like (50/51/49/87), 100% verde.

### Fase γ (gamma) — Damage Curves Overlay

#### γ.1 — Cable damage curve
- Baseado em IEC 60364 / NBR 5410: `t_damage = K²·S² / I²`
- Implementação como `TCCSegmentI2T` parametrizado pelo material+seção do cabo
- Plot tracejado vermelho no coordenograma

#### γ.2 — Transformer through-fault
- IEEE C57.109: 4 categorias (frequent/infrequent + small/medium/large)
- Curve table embedded

#### γ.3 — Motor thermal limit (locked rotor + accel)
- IEC 60079-7 / NEMA MG-1
- Locked rotor heating curve

**Aceite γ**: 20+ testes, integração com `tcc_coordinogram.py`, 100% verde.

## Glossário (anti-confusão)

| Termo | Significado |
|---|---|
| **TCC Segment** | Pedaço atômico de uma curva tempo-corrente (ex: pickup LT, instantâneo 50, definite-time delay). 17 tipos. |
| **TCC Curve** | (Legacy v1.1.0) curva única de relé com 1 característica inverse-time + opcional 50. |
| **Fuse TCC Curve** | (Legacy v1.1.0) curva dupla de fusível (melt + clear). |
| **TCC Device** (β) | Dispositivo de proteção com múltiplos segments (relé com 50/51/49/87). |
| **Multi-function relay** | Subclasse de TCCDevice especializada para relés digitais. |
| **Damage curve** | Curva limite de equipamento (cable, XFMR, motor) que NÃO deve ser cruzada por curva de proteção. |
| **Composite envelope** | Função `min(t_segment)` aplicada num device — descreve o que acontece de fato no fault. |
