## 3. Sprints — todos GREEN

### Sprint 1 — N tabs por PropertyGroup (12/12 ✅)

`app/gui/schematic_pp/property_editor.py` — `ComponentPropertyDialog` reescrito:

- **Antes** (pré-v3.2.0): 2 tabs (Parâmetros / Descrição). Todos os
  PropertyGroupBox empilhados na primeira tab.
- **Agora**: 1 tab por PropertyGroup com properties no grupo. Tabs vazios
  são omitidos (clean UX). MAIN sempre presente como ancora visual.

**Tabs criados** para BREAKER (exemplo):
```
📋 Principal | ⏱ Timing | ⚙ Avançado | 📄 Descrição
```

### Sprint 2 — Heurística canônica + ícones (incluso em Sprint 1) ✅

- `_TAB_ORDER` constante: ordem canônica PTW
  (MAIN → ELECTRICAL → NONLINEAR → GEOMETRY → TIMING → REIGNITION → THERMAL → ADVANCED → METADATA)
- `_TAB_ICON` mapping: ícone unicode por grupo
  (📋 ⚡ 📈 📐 ⏱ 🔥 🌡 ⚙ 🏷)
- "Descrição" sempre como **última tab** (descrição + llm_hints renderizados em HTML)
- `_created_tabs` lista para test/audit (verifica 7ª garantia)

### Sprint 3 — Datablock tab integration ✅

- Novo método `ComponentPropertyDialog.attach_datablock_tab(datablocks)`
- Inserido **antes** da Descrição, com lista de previews dos datablocks
- `editor.py:_open_modal_dialog` chama `_datablocks_for_component()`
  para buscar `PpDataBlock` com `component_name == item.component.name`
  e passa para o dialog
- Tab "📊 Datablocks" só aparece se há datablocks anexados

### Audit retroativo — linked_library wiring (5ª task) ✅

`build_property_rows()` agora propaga `cur_linked = component.properties[idx].linked_library`
para o `PropertyRow(linked_library=...)`. Antes da v3.2.0:
- Backend tinha o flag (v3.1.1 model)
- UI tinha o suporte (v3.1.2 PropertyRow)
- **Gap**: factory não passava o flag → UI nunca via linked

**Fix critical** para 7ª garantia: feature agora **acessível** ao
usuário (gray-out + botão Unlink visíveis quando o backend tem o flag).

## 6. Smoke Test Manual

> 1. Abrir Olivas → criar um BREAKER no canvas (paleta → push-pin)
> 2. **Duplo-clique no BREAKER** → abre Component Editor
> 3. Aparecem **4 tabs**: 📋 Principal · ⏱ Timing · ⚙ Avançado · 📄 Descrição
> 4. Clicar em ⏱ Timing → ver props `operating_time_ms`, `arc_time_ms`
> 5. Clicar em ⚙ Avançado → ver `relay_link_tag`
> 6. Clicar em 📄 Descrição → ver HTML com llm_hints
>
> **Para Datablock tab**:
> 1. Right-click no BREAKER → "Adicionar datablock" → preencher
> 2. Duplo-clique no BREAKER de novo → agora aparece **5 tabs** com 📊 Datablocks
>
> **Para linked_library gray-out**:
> 1. Em código (ou via library link future): `prop.linked_library = "ABB HD4"`
> 2. Reabrir Component Editor → property aparece **cinza + readonly + botão 🔗**
> 3. Clicar 🔗 → emite signal para unlink

## 7. Anti-alucinação — limitações declaradas

1. **Tabs criadas dinamicamente por componente** — alguns componentes
   (R, L, C básicos) só têm props em MAIN, então mostram apenas 2 tabs
   (📋 Principal + 📄 Descrição). Isto é **correto** (não duplicar tabs vazias).

2. **Dialog para insert linked_library** ainda não criado — o flag pode
   ser setado via código, mas não há UI para o usuário ligar uma property
   a uma library. Será criado quando v3.2.x integrar com EquipmentLibraryDialog.

3. **Datablock tab é read-only preview** — edição de datablocks ainda é
   via duplo-clique no canvas (via `DataBlockItem`). Tab apenas mostra preview.
