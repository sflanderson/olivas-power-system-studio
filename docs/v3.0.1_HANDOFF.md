## 3. Deep audit CAPTOR — descobertas chave

### 3.1 17 Segment Types canônicos (PTW Reference-CAPTOR §2.2.1-2.2.17)

Lista completa extraída do manual com seção+página: 17 segments cobrindo
fuses, time-current, pickup variants, delay bands, I²t, equação clássica
ANSI/IEC, polinomial motor protector, fixed time horizontal.

### 3.2 10 ANSI/IEC standard curves com constantes (§2.8.2 p. 2-107)

Tabela canônica extraída do manual: 8 ANSI (S/L/D/M/I/V/E/F) + 2 IEC
BS142 (B/C). Cobre Short Inverse, Long Inverse, Definite Time,
Moderately Inverse, Inverse, Very Inverse, Extremely Inverse.

### 3.3 10 oportunidades de SUPERAÇÃO identificadas

1. Damage curve gap declarado (PTW §3.1) — Olivas pode entregar built-in
2. 17 segments redundantes → 4 primitives + decorators
3. Manual constant entry → embed IEC 60255-151 + IEEE C37.112 nativamente
4. 1 function/TCC apenas → mostrar N functions simultâneas (50+51)
5. DOS legacy import → schema YAML versionado
6. Sem CIM/IEC 61850 import → SCD/CID + COMTRADE export
7. Single voltage reference → auto-shift por turns ratio
8. Sem validation engine → selectivity verifier auto
9. Datablock = spreadsheet 2000s → JSON/XLSX/PDF + hash
10. No plugin API → Python plugin para custom segments
