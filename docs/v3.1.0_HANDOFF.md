## 6. Smoke Test Manual — Como o usuário usa as features

### 6.1 ANSI Short Circuit (C37.5 / C37.010)

> Para rodar um estudo ANSI Comprehensive Short Circuit:
> 1. Abrir Olivas
> 2. Menu **Análise** > **🇺🇸 ANSI Short Circuit (C37.5 / C37.010)...** (ou atalho **Ctrl+Shift+A**)
> 3. Aba **Inputs**: definir bus name, kV, I_sym, X/R, ANSI standard, NACD mode, breaker cycle
> 4. Aba **Generators**: editar tabela de contribuições (add/remove rows)
> 5. Clicar **Calcular**
> 6. Aba **Reports** mostra LV / Momentary / Interrupting + Asym Withstand
> 7. Clicar **Exportar...** para salvar TXT (PTW-style) / Markdown / CSV

### 6.2 Pre-Fault Voltage Settings

> 1. Menu **Análise** > **⚙️ Pre-Fault Voltage Settings...**
> 2. Selecionar mode (PU_ALL / NO_LOAD_WITH_TAP / PU_PER_BUS / LOAD_FLOW)
> 3. Editar tabela Min/Reg/Max para Util / Cable / TX
> 4. Selecionar scenario para combined calculator (max/regular/min)
> 5. OK persiste; Cancel descarta; Reset volta defaults

### 6.3 ANSI Utilities (3-em-1)

> 1. Menu **Ferramentas** > **🛠 ANSI Utilities (Mis-coord / Conversion / TX Tap)...**
> 2. Tab **Mis-Coordination**: ajustar threshold + trip times + correntes → verdict color-coded
> 3. Tab **C37.5 ↔ C37.010**: input R+X complex → X/R; input current+factor → conversion
> 4. Tab **Transformer Tap**: NEMA 5-step → V_sec; Z0/Z1 → SLG/3-φ ratio

### 6.4 Fault Current Decay (temporal)

> 1. Menu **Análise** > **📉 Fault Current Decay (temporal)...**
> 2. Selecionar source (Generator / Sync / Induction)
> 3. Para Gen/Sync: ajustar I_sub, I_steady, τ → tabela 10 pontos
> 4. Para Induction: ajustar hp + threshold + cycles_after → tabela com EXCLUDED/Active

### 6.5 Run > Balanced System Studies

> 1. Menu **Análise** > **🏃 Run > Balanced System Studies (DAPPER + LF + Comp SC)...**
> 2. Marcar checkboxes dos 4 estudos desejados
> 3. Clicar **▶ Run all selected**
> 4. Log mostra progresso + pointer para cada dialog standalone

## 7. Anti-alucinação — limitações declaradas

1. **Load Flow ainda parcial**: o orchestrator B-5 aponta para Análise > Fluxo de potência, mas implementação completa N-R + GS + FDLF está deferred para v3.3.0.

2. **DAPPER demand load**: é dialog separado (Análise > Demand Load Study), não integrado ao orchestrator B-5 (apenas referenciado via log).

3. **Mis-coordination**: dialog test pair (1 main vs 1 backup); detecção em **toda** a topologia (multi-device search) está em backend mas precisa loop UI iterativo (deferred v3.1.1).

4. **Pre-Fault Voltage Settings persistence**: `get_settings()` retorna dict para o caller, mas auto-aplicar em estudos subsequentes (signal/QSettings) deferred v3.1.1.

5. **Track A One-line Editor (Tier 1 fundacional XL, 6-8 sem)**: deferred para v3.1.1+, não cabe junto com Track B no escopo de v3.1.0.
