## 1. Architecture decisions

### 1.1 Module split

```
app/
├── gui/
│   ├── ct_saturation_dialog.py     ← orchestrator (Dialog + tabs)
│   └── ct_saturation_plots.py      ← NEW: 3 plot functions (no-Qt-state)
└── postprocessor/
    ├── ct_saturation.py             ← unchanged backend
    └── ct_saturation_io.py          ← NEW: JSON loader + TXT/XLSX writers
```

**Razão**: separar responsabilidades. `*_plots.py` recebe `report` e
retorna `Figure`, sem conhecer Qt. Permite teste headless com matplotlib
Agg backend (rápido) sem precisar QApplication para o teste do plot
puro. Apenas o teste do dialog precisa de QApplication.

### 1.2 Plot signature padrão

```python
def plot_level1_ansi(
    report: CTSaturationReport,
    fig: Figure | None = None,
) -> Figure:
    """Returns Figure — caller embeds via FigureCanvasQTAgg."""
```

Fig é opcional para permitir reuso (ex: dialog reusa o mesmo fig
ao re-analisar).

### 1.3 Cores — paleta consistente com MATLAB

```python
# Constantes em ct_saturation_plots.py
COLOR_PASS = (0.466, 0.674, 0.188)   # verde MATLAB
COLOR_FAIL = (0.85, 0.325, 0.098)    # vermelho MATLAB
COLOR_PRIMARY = (0, 0.447, 0.741)    # azul barra capacidade
COLOR_KNEE = (0, 0.5, 0)             # verde escuro joelho IEC

ZONE_SAFE = (0.85, 1.0, 0.85)        # verde claro (pré-trip)
ZONE_TOLERANCE = (1.0, 1.0, 0.9)     # amarelo claro (margem)
ZONE_SATURATION = (1.0, 0.85, 0.85)  # vermelho claro (saturação)
```

## 4. Sprint C — Plot N3 (Dinâmico, 2 subplots)

### Contrato

```python
def plot_level3_dynamic(report, fig=None) -> Figure:
    """
    2 subplots empilhados:
      (1) Fluxo λ(t) com 3 zonas + marcadores
      (2) Correntes ideal vs real + área de erro
    Replica MATLAB run_level3_dynamic.m §5.
    """
```

### Estrutura — Subplot 1 (fluxo)

* `ax1 = fig.add_subplot(2, 1, 1)`
* Zona safe `ax1.axvspan(0, t_relay_ms, color=ZONE_SAFE, alpha=0.5)`
* Se `t_sat_ms` finito:
  - Zona saturação `ax1.axvspan(t_sat_ms, t_sim_end, color=ZONE_SATURATION, alpha=0.5)`
  - Se `t_sat_ms > t_relay_ms`: zona tolerância
    `ax1.axvspan(t_relay_ms, t_sat_ms, color=ZONE_TOLERANCE, alpha=0.5)`
  - Linha vertical: `ax1.axvline(t_sat_ms, color='red', ls='--')` + label
* Curva fluxo: `ax1.plot(t_arr_ms, lambda_arr, 'k-', lw=2)`
* Limites joelho: `ax1.axhline(±λ_knee, color='red', lw=2)`
* Trip xline verde + marcador azul `ax1.plot(t_relay, λ_at_trip, 'bo', mfc='b', ms=8)`
* Info box: `ax1.text(t_relay, λ_at_trip + 0.15·λ_knee, ...)` com
  bbox dict (white background, blue edge)

### Estrutura — Subplot 2 (correntes)

* `ax2 = fig.add_subplot(2, 1, 2)`
* Mesmas zonas com α=0.3
* `ax2.plot(t_arr_ms, i_st, 'r--', lw=1, label='I_sec Ideal')`
* `ax2.plot(t_arr_ms, i_s_real, 'b-', lw=1.5, label='I_sec Real')`
* Área de erro: `ax2.fill_between(t_arr_ms, i_st, i_s_real, color='red', alpha=0.2)`
