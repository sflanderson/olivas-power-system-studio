## 5. User testing gate (5 passos visuais)

Antes de prosseguir para v1.5.0:

1. ✅ Abrir Olivas → Pós-processamento → CT Saturation
2. ✅ Defaults C400@2000:5 → ver 4 tabs com plots
3. ✅ Carregar `ct_system_data.json` → escolher CT-0200-PN-0001-01 →
   ver 4 tabs atualizadas
4. ✅ Salvar TXT + XLSX → abrir e conferir conteúdo
5. ✅ Forçar caso falho (C100@2000:5 + Icc 28 kA) → clicar
   "Re-dimensionar" → ver classe atualizar (C100→C200) + plots
   regenerarem

Se algum dos 5 passos falhar visualmente, **NÃO prosseguir** —
abrir bug report.
