## 6. Smoke Test Manual

### 6.1 Push-pin placement (Sprint 1)
> 1. Abrir Olivas → click qualquer componente na paleta lateral (ex: "R")
> 2. Cursor vira cruz (cross), entra em **TOOL_PIN** mode
> 3. Click no canvas em N posições — cada click coloca uma instância
> 4. Esc ou tecla V volta para SELECT mode

### 6.2 Util / Load / Filter (Sprint 2)

> 2. Drag-drop ou click + canvas-click coloca instância

   inserção). Defered para v3.1.2.

   ainda **não serializam** no formato Qucs `.sch` (model existe mas
   round-trip preservation deferred v3.1.2).
