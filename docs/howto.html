Como executar um estudo?

Olivas ATP Studio — ATP Power System Simulation

Olivas ATP Studio oferece três caminhos de execução. Este guia também é acessível em qualquer momento via tecla F1 ou Ajuda → Como executar?

1. ▶ Simulação ATP (transitórios eletromagnéticos)

Para rodar simulação no solver ATP/EMTP:

  • Caso o esquemático esteja no Esquemático Visual, clique em Exportar ATP primeiro.
  • Configure o caminho do solver: Simulação → Configurar caminho ATP.
  • Clique no botão ▶ azul na toolbar superior, ou Simulação → Executar ATP.
  • Saída: arquivos .pl4, .lis em runs/.
Pré-requisito: ATP/EMTP solver instalado (não distribuído com o ATP Studio — licença BPA). Use tpgigg32.exe para casos grandes.

2. ▶ Executar Análise (estudos profissionais)

No Esquemático Visual, clique no botão verde ▶ Executar Análise da toolbar (ou menu Análise).

3. 📚 Exemplos das normas

Menu Exemplos oferece 6 worked examples com esquemáticos pré-preenchidos:

  • Stevenson §9 — Power Flow 3-bus
  • Stevenson §11 — Faltas Assimétricas
  • IEC 60909 Annex C — SC com transformador
  • IEEE 1584 D.4 — Arc-flash 480V VCB
  • IEEE 399 §10 — Partida Motor 1500 kW
  • NBR 17227 — Switchgear 13.8 kV

Cada exemplo carrega o esquemático .sch no editor visual + executa o cálculo + exibe relatório expected vs computed.

O que é "BUS"?

O componente BUS representa um barramento elétrico com metadata específica para arc-flash + coordenação:

  • V_LL (kV) — tensão linha-linha
  • panel_type — CCM, switchgear, LV panel
  • is_lineside — vs loadside
  • has_AFD — Arc Fault Detection
  • n_taps — número de feeders

Adicione via Paleta → BUS, ou nos exemplos das normas que já o trazem configurado.

Configurar API Claude

Para habilitar o assistente Claude no editor visual e no chat global:

  • Simulação → Configurar API Key Claude...
  • Cole sua chave (sk-ant-...) e teste.
  • Persistente via QSettings.
