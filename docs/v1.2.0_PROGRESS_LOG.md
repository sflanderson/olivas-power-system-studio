**Entregue**: 2 segments analíticos paramétricos cobrindo as fórmulas PTW CAPTOR.

  - TestTCCSegmentAnalyticAD (7 tests): pickup boundary, **3 canonical tests** validando contra `operating_time_s` legacy (ANSI Mod-Inv, ANSI VI, IEC SI), large C shift, disabled, points
  - TestTCCSegmentAnalyticSM (6 tests): below C inf, well above C finite, SM scales linearly, disabled, negative poly inf, points
  - TestProtocolConformance (2 parametrized): conformance ao Protocol

**Anti-alucinação confirmada**: as 3 verificações canônicas garantem que a fórmula AD coincide bit-a-bit com `operating_time_s(curve_type, M, tms=1.0)` legacy quando parametrizada com os mesmos coeficientes de IEEE C37.112-2018. Isto significa que TODAS as 7 curve types pré-existentes (4 IEC + 3 ANSI) podem ser representadas como `TCCSegmentAnalyticAD` — o segment é compatível.

**Edge cases tratados explicitamente**:
- `M^N - C ≤ 0` → inf (pickup efetivo)
- `M ≤ C` na SM → inf (divisor zero/negativo)
- Polynomial cai abaixo de zero → inf (não-físico)
- ZeroDivisionError, OverflowError, ValueError → inf
