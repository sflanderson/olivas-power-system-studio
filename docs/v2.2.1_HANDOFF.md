## 1. Resumo

v2.2.0 entregou GOOSE/SV em stub mode (lógica de protocolo, sem
serialização). v2.2.1 adiciona o **wire format real**: encoder/
decoder ASN.1 BER (ITU-T X.690) com PDU encoders estruturais
para GOOSE e SV.

Bytes produzidos são **válidos BER** — qualquer parser ASN.1
genérico (Python `pyasn1`, Wireshark, etc) lê os PDUs
corretamente. Para interop byte-by-byte com IED real,
ainda exige libiec61850 (deferred).

## 3. Sprints

### Sprint A+B — BER Primitives ✅ (15 testes)
NEW `app/integration/iec61850_ber.py` (~330 LOC):

**Encoders + decoders**:
- `encode_integer(n)` / `decode_integer(data)` (X.690 §8.3)
  - Tag 0x02, two's complement, padding 00/FF para sign
- `encode_boolean(b)` / `decode_boolean(data)` (X.690 §11.1)
  - Tag 0x01, TRUE=0xFF (DER canonical), FALSE=0x00
- `encode_octet_string(b)` / `decode_octet_string(data)` (X.690 §8.7)
  - Tag 0x04, length + raw bytes
- `encode_visible_string(s)` / `decode_visible_string(data)`
  - Tag 0x1A (ISO 646)
- `encode_length(n)` / `decode_length(data)` (X.690 §8.1.3)
  - Short form (<128) + long form (≥128: 0x8X + bytes)

**Golden values validados**:
| Input | Output bytes |
|-------|--------------|
| INTEGER 0 | `02 01 00` |
| INTEGER 127 | `02 01 7F` |
| INTEGER 128 | `02 02 00 80` (padding 00 para preservar +) |
| INTEGER -1 | `02 01 FF` |
| BOOLEAN TRUE | `01 01 FF` |
| BOOLEAN FALSE | `01 01 00` |
| OCTET STRING vazio | `04 00` |
| VisibleString "Hi" | `1A 02 48 69` |
| Length 128 | `81 80` |
| Length 256 | `82 01 00` |

**Round-trip tests**: encode → decode → input idêntico para
INT/BOOL/OCTET/VisibleString.

### Sprint C — GOOSE PDU Encoder ✅
`encode_goose_pdu(GooseMessage)` produz BER bytes seguindo
estrutura IEC 61850-8-1 §17.2.5:

```
GoosePdu ::= [APPLICATION 1] IMPLICIT SEQUENCE {
    gocbRef             [0] IMPLICIT VisibleString,
    timeAllowedToLive   [1] IMPLICIT INTEGER,
    datSet              [2] IMPLICIT VisibleString,
    goID                [3] IMPLICIT VisibleString,
    t                   [4] IMPLICIT UtcTime,
    stNum               [5] IMPLICIT INTEGER,
    sqNum               [6] IMPLICIT INTEGER,
    test                [7] IMPLICIT BOOLEAN,
    confRev             [8] IMPLICIT INTEGER,
    ndsCom              [9] IMPLICIT BOOLEAN,
    numDatSetEntries    [10] IMPLICIT INTEGER,
    allData             [11] IMPLICIT SEQUENCE OF Data
}
```

Tag inicial 0x61 = APPLICATION 1 constructed.

### Sprint D — SV ASDU Encoder ✅
`encode_sv_asdu(sv_id, smp_cnt, samples)` produz BER seguindo
IEC 61850-9-2 §6.2:

```
ASDU ::= SEQUENCE {
    svID    [0] IMPLICIT VisibleString,
    smpCnt  [2] IMPLICIT OCTET STRING (16 bits BE),
    confRev [3] IMPLICIT OCTET STRING (32 bits BE),
    smpSynch [5] IMPLICIT OCTET STRING (1 byte),
    sample  [6] IMPLICIT OCTET STRING (samples int32 BE)
}
```

## 4. Cobertura normativa

| Norma | Implementação |
|-------|---------------|
| ITU-T X.680:2021 | Universal class tags + IMPLICIT context-specific |
| ITU-T X.690:2021 §8.1.3 | Length encoding (short/long form) |
| ITU-T X.690:2021 §8.2 + §11.1 | BOOLEAN canonical |
| ITU-T X.690:2021 §8.3 | INTEGER two's complement |
| ITU-T X.690:2021 §8.7 | OCTET STRING |
| IEC 61850-8-1:2020 §17.2.5 | GOOSE PDU structure |
| IEC 61850-9-2:2020 §6.2 | SV ASDU structure |

## 5. Limitações declaradas (anti-alucinação)

* **Wire format não-100%-IEC-compliant**: PDU bytes são BER válidos
  (qualquer parser ASN.1 lê), mas **detalhes específicos do
  IEC 61850** (codificação UtcTime exata, smpSynch flags, etc)
  são simplificados.
* **Sem serialização Ethernet**: produzimos BER bytes; encapsulamento
  em frame Ethernet (EtherType 0x88B8 GOOSE / 0x88BA SV) seria
  layer adicional.
* **Tags multi-byte (>=31)** não implementados — IEC 61850 usa
  tags 0..14, dentro do limite single-byte.
* **Indefinite length** não suportado (raise ValueError).
* Para **interop real com IED**: usar libiec61850 (real mode).
