## 2. Sprint A — Manifest schema (Pydantic)

### Schema (YAML)

```yaml
schema_version: "1.0"
name: solar_pv_yield
display_name: Solar PV Yield Calculator
version: "1.0.0"
author: Olivas Team
license: MIT
description: |
  Calcula yield anual de sistema fotovoltaico baseado em
  irradiação solar local (NSRDB) e parâmetros do painel.

# Compatibilidade com Olivas
min_olivas_version: "1.5.0"
max_olivas_version: null   # null = sem limite

# Categoria (Marketplace UI)
category: study              # study | equipment | renderer | exporter
                             # postprocessor | validator | catalog_spec

# Entry point (Python module path relativo ao plugin folder)
entry_point: plugin.py

# Permissions declaradas (whitelist)
permissions:
  - studies                  # registra novo study via @register_study
  - filesystem.read          # lê arquivos .csv/.json
  # - filesystem.write       # escreve arquivos
  # - network                # acessa internet (NSRDB API)
  # - subprocess             # executa comandos externos

# Hash SHA256 do plugin.py (para detectar tampering)
content_sha256: "abc123..."

# Tags para busca no marketplace
tags: [solar, photovoltaic, yield, nsrdb, brazil]
```

### Pydantic models

```python
class PluginPermission(str, Enum):
    STUDIES = "studies"
    EQUIPMENT = "equipment"
    RENDERERS = "renderers"
    EXPORTERS = "exporters"
    POSTPROCESSORS = "postprocessors"
    VALIDATORS = "validators"
    CATALOG_SPECS = "catalog_specs"
    FILESYSTEM_READ = "filesystem.read"
    FILESYSTEM_WRITE = "filesystem.write"
    NETWORK = "network"
    SUBPROCESS = "subprocess"


class PluginCategory(str, Enum):
    STUDY = "study"
    EQUIPMENT = "equipment"
    RENDERER = "renderer"
    EXPORTER = "exporter"
    POSTPROCESSOR = "postprocessor"
    VALIDATOR = "validator"
    CATALOG_SPEC = "catalog_spec"


class PluginManifest(BaseModel):
    schema_version: str = "1.0"
    name: str = Field(min_length=2, max_length=64,
                     pattern=r"^[a-z][a-z0-9_]*$")
    display_name: str
    version: str
    author: str
    license: str = "Unknown"
    description: str
    min_olivas_version: str
    max_olivas_version: str | None = None
    category: PluginCategory
    entry_point: str = "plugin.py"
    permissions: list[PluginPermission] = []
    content_sha256: str | None = None
    tags: list[str] = []

    @validator("version", "min_olivas_version")
    def _semver(cls, v):
        # Aceita "1.0.0", "1.0", "1"
        parts = v.split(".")
        for p in parts:
            int(p)   # lança se não-int
        return v
```

## 3. Sprint B — Discovery v2 + Lifecycle

### Discovery hierarchy (3 sources)

```python
def discover_plugins_v2() -> list[DiscoveredPlugin]:
    """
    Descobre plugins de 3 fontes (em ordem):

    1. BUILTIN: app/plugins/builtin/<name>/manifest.yaml
       (plugins shipped com Olivas, sempre disponíveis)

    2. INSTALLED: ~/.olivas/plugins/<name>/manifest.yaml
       (plugins instalados pelo usuário, persistidos)

    3. PROJECT: ./plugins/<name>/manifest.yaml
       (plugins do projeto atual, opcional)
```

## 4. Sprint C — Security: Permissions + SHA256 + Install

### Permission gating

Antes de **carregar** um plugin (importar o module), validar:

1. Manifest é válido (Pydantic)
2. SHA256 do `plugin.py` casa com `content_sha256` do manifest
3. Permissões estão na whitelist conhecida
4. Versão Olivas está no range `[min, max]`
5. Usuário **aprovou** as permissões (lifecycle state)

Se alguma falhar: skip + log warning. **Nunca** carrega plugin
não-aprovado.

### Install workflow

```
User clica "Install" em plugin do catálogo
  → mostra ConfirmDialog com:
      * Manifest details (name, author, version, description)
      * Permissions list (com explicação de cada uma)
      * SHA256 hash
      * Botões: "Confirmar e instalar" / "Cancelar"
  → se confirmar:
      * Copia para ~/.olivas/plugins/<name>/
      * Atualiza state.json com approved_permissions
      * Não carrega ainda (carrega na próxima sessão para
        evitar instabilidade)
```
