## 2. Gap exato a fechar (4 standards)

### 2.1 NESC 2023 §410 (Sprint A)

**Tipo**: tabela prescritiva (não-fórmula). Baseada em system voltage,
determina:
* **Approach Boundary** (mm) por voltage range
* **PPE rating mínimo** (cal/cm²)
* **Working distance** recomendada

NESC 2023 Table 410-1 (Phase-to-ground exposure) e Table 410-2
(Phase-to-phase exposure). **Diferente** do IEEE 1584: NESC é
prescritivo, não calcula incident energy a partir de Ibf+t.

**Anti-alucinação**: como não temos NESC 2023 literal disponível,
implementaremos a **estrutura** com valores típicos public-domain
(citados em IEEE textbooks que referenciam NESC) + flag
`verify_against_nesc_2023_official=True` para alertar usuário.

### 2.2 Doughty-Neal-Floyd 2000 (Sprint B)

**Fonte primária**: Doughty, Neal, Floyd, *"Predicting Incident
Energy to Better Manage the Electric Arc Hazard on 600-V Power
Distribution Systems"*, IEEE Trans Industry Applications,
Vol. 36, No. 1, Jan/Feb 2000.

**Fonte secundária acessível**: IEEE 1584-2002 Annex B reproduziu
o método. As fórmulas:

* Open-air arc (D < 18 in / 455 mm):
  ```
  E_MA = 5271 · D^(-1.4738) · t · (0.0016·Ia² - 0.0076·Ia + 0.8938)
  ```
  E em cal/cm², D em mm, Ia em kA, t em segundos.

* Arc in box (D < 24 in / 610 mm):
  ```
  E_MB = 1038.7 · D^(-1.4738) · t · (0.0093·Ia² - 0.3453·Ia + 5.9675)
  ```

**Range**: V_oc ≤ 600 V (sistemas LV apenas). É um método **legacy**
ainda referenciado em CSA Z462 e quando IEEE 1584 não é aplicável.

### 2.3 DC arc flash (Sprint C)

**Fontes**:
* NFPA 70E:2024 §D.5 — método de potência máxima
* Stokes & Oppenheim 1991 (paper original)
* Wilkins 2003/2005 — refinement

**Método NFPA 70E §D.5 (max power)**:
```
P_max = V_arc · I_arc       (W)
V_arc = 0.5 · V_system       (max power transfer)
I_arc = V_system / (2·R)     (R = system resistance)
E = P_max · t / (4π·D²·6.7)  (esférica, distance D em cm)
```

`6.7` é um fator de cal/cm² conversion + esférica.

### 2.4 CSA Z462 (Sprint D)

**Fonte**: CSA Z462-21 (Workplace Electrical Safety), Annex D.1
referencia **IEEE 1584-2018** explicitamente.

**Diferenças** vs NFPA 70E:
* Tabelas PPE category labels diferentes (CSA usa "Risk Category 1-4"
  vs NFPA "PPE Category 1-4" — mesma classificação, naming distinto)
* Working distance defaults distintos para alguns equipamentos
* DC arc-flash referencia método híbrido Wilkins/Stokes

**Implementação**: wrapper sobre `arc_flash.py` (IEEE 1584) +
tabelas PPE CSA-specific + DC method da Sprint C.

## 3. Vantagem competitiva v1.6.0

| Software | Standards arc-flash |
|----------|--------------------|
| SKM PTW Power*Tools | IEEE 1584 |
| EasyPower | IEEE 1584 + NFPA 70E annex |
| ETAP | IEEE 1584 + DC method |
| **Olivas v1.6.0** | **IEEE 1584 + NBR 17227 + EPRI + Terzija + NESC + Doughty-Neal + DC + CSA Z462 (8 standards!)** |

Comparison view: usuário insere **um caso** (Voc, Ibf, t, D), Olivas
roda **todos os standards aplicáveis** e mostra side-by-side. Útil
para:
* Comparação reglatória entre projetos US/CA/BR
* Sanity check (se 2 standards divergem >50%, alertar)
* Documentação de auditoria (mostra qual standard é mais conservador)
