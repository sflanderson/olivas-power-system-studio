### API

```python
def compute_demand(
    entries: list[LoadEntry],
    *,
    catalog: dict[str, DemandCategory] | None = None,
) -> DemandReport:
    """
    Aplica multi-level demand factor por categoria.

    1. Agrupa entries por category_code
    2. Para cada categoria: aplica os 3 levels da tabela
       (kVA limit + percent)
    3. Soma os Demand Loads → bus_demand_kVA
    4. Multiplica pelo LCL → design_kVA
    """
```

### Algorithm (multi-level demand)

```python
def apply_demand_levels(
    connected_kVA: float, levels: tuple[DemandLevel, ...]
) -> float:
    """
    Aplica os 3 níveis cumulativamente.

    Exemplo NEC 220.42 (3000 @ 100%, 120000 @ 35%, ALL @ 25%):
      connected = 200_000 VA
      level 1: min(200000, 3000) × 100% = 3000
      level 2: min(200000-3000, 117000) × 35% = 40_950
      level 3: max(0, 200000-120000) × 25% = 20_000
      total = 63_950 VA
    """
    remaining = connected_kVA
    total = 0.0
    for lvl in levels:
        if remaining <= 0:
            break
        if lvl.kVA_limit is None:
            chunk = remaining
        else:
            chunk = min(remaining, lvl.kVA_limit)
        total += chunk * lvl.demand_pct / 100.0
        remaining -= chunk
        if lvl.kVA_limit is None:
            break
    return total
```
