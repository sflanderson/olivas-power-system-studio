## 7. Anti-alucinação — limitações declaradas

1. **§1.4.1 momentary report**: implementado parcialmente — apenas
   `sym_x_1_6` e `sym_x_2_7` (PTW simplificados). Os campos
   `Mom-X/R` e `Crest-X/R` usam fórmula Eq 7-1 com c=0.5; valores
   podem divergir 1-2% dos publicados.

2. **DAPPER solver não implementado**: as correntes E/Z e Z complex
   são INPUTS do `AnsiFaultBus`, não calculadas internamente. Para
   reproduzir os Cases §1.4 end-to-end com solver DAPPER completo,
   defer para v3.3.0 (Load Flow + IEC 60909).

3. **Comprehensive Study output não inclui Sub-Reports** (Phase A,
   Phase B, Phase C separadamente) — apenas o aggregate. Para
   completude, defer para v3.0.6 ou v3.3.0.
