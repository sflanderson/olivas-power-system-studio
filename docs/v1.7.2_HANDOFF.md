1. ✅ Abrir Olivas → ver versão `2.0.1`
2. ✅ Adicionar BREAKER + RELAY + CT no canvas → ver **pin dots

5. ✅ F5 → marcar SC + Executar → Visualizar > Resultados >
   Contribuição das Fontes (SC) → dock **abre populado** se
   houver SC result; ou dock **atualiza** se já estava aberto

## 7. Gap declarado (anti-alucinação)

**Power Flow no F5 ainda não roda** — `solve_power_flow()` API
existe mas não é chamado pelo dialog. PF Voltage Profile dock
continua em empty state após F5. Documentado em
`v1.7.2_BACKLOG_AUDIT.md` §3 e em `SESSION_HANDOFF.md` §4.1
(deferred para v1.7.3+).

## 8. Continuation protocol ativado

`docs/SESSION_HANDOFF.md` é **fonte de verdade entre sessões**.
Próxima sessão deve:

1. Ler `SESSION_HANDOFF.md` PRIMEIRO
2. Verificar versão atual via `python -c "from app.core.version
   import VERSION; print(VERSION)"`
3. Rodar sweep targeted recente para validar estado
4. Continuar com próximo passo sugerido (v1.7.3 — Power Flow F5)
