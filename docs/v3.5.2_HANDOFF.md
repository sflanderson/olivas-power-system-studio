## 3. Sprint A.1 — AddLinkTagDialog

### Antes (v3.5.1)
`editor._on_add_link_tag` usava 2 `QInputDialog.getText` sequenciais —
sem preview, sem combo de scheme, sem toggles, sem Browse para PDFs.

### Depois (v3.5.2)
NEW `app/gui/add_link_tag_dialog.py` (~210 LOC):

* **`TARGET_SCHEMES`** tuple — 4 schemes documentados (oneline/tcc/report/pdf)
* **`LinkTagFormData`** dataclass — result of dialog acceptance
* **`AddLinkTagDialog`** QDialog:
  - Label QLineEdit
  - Scheme QComboBox (com tooltip por scheme)
  - Target QLineEdit + Browse... button (enabled apenas para `pdf:`)
  - Visible QCheckBox (default True)
  - Closed arrow QCheckBox (default True)
  - Preview live QLabel (peach background, atualiza com signals)
  - QDialogButtonBox OK/Cancel

### Wiring
`editor._on_add_link_tag` substituído (apenas 1 dialog em vez de 2);
mantém compatibilidade com `AddLinkTagCommand` undo stack.

## 4. Sprint A.2 — MainWindow document registry

### Antes (v3.5.1)
`oneline:DocName` Link Tags só mostravam status message
`"navegação multi-doc disponível em v3.2.0+"`.

### Depois (v3.5.2)
NEW em `MainWindow` (4 métodos públicos):

```python
def register_document(self, name: str, widget) -> None: ...
def unregister_document(self, name: str) -> None: ...
def list_documents(self) -> list[str]: ...
def navigate_to_document(self, name: str) -> bool: ...
```

* **`_documents_registry: dict[str, QWidget]`** — initialized at MainWindow ctor
* **Default**: schematic_pp registrado como `"Main"` (assim
  `oneline:Main` funciona out-of-the-box)
* **`_on_link_tag_navigate`** scheme `oneline` agora consulta o
  registry; se não encontra documento, mostra QMessageBox com lista
  de docs registrados

### Reference
PTW Tutorial §Part 1 p.30-34 (multi-document navigation).

## 9. Anti-alucinação — limitações declaradas

1. **A.1 dialog não persiste user defaults** — toda abertura usa
   `default_label="Ver TCC-A"`, `default_target="tcc:CoordA"`. Preferência
   por user (lembrar última escolha) deferred para v3.6.x.

2. **A.2 registry é per-sessão** — não persiste em disco. Ao recarregar
   projeto, apenas `Main` é reregistrado. Persistência de registry em
   `.olivas-project.json` deferred.

3. **A.2 não cria docs ausentes** — se `oneline:DocB` não está
   registrado, mostra mensagem mas não oferece "criar agora". Open
   document dialog deferred.

4. **A.1 sem color picker** — `PpLinkTag` não tem campo `color`
   (paleta fixa via `_LINK_TAG_LINE` / `_LINK_TAG_FILL` em
   `tag_items.py`). Color picker no dialog seria UX dead-end.
