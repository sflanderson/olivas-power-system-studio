## 8. Anti-alucinação — limitações declaradas

1. **C-lines: IE formula simplificada** — `compute_c_line_ieee_1584` usa
   E_n ≈ 0.5 × I_kA^1.2 (calibração para 480V/box). Para precisão IEEE 1584
   completa (curva real do arc-flash), v3.4.x pode adicionar ramo Lee/Stokes/etc.

2. **C-lines visual rendering deferred** — `_on_c_lines_toggled` armazena
   curves em `_c_lines` attr; o **paint** real no canvas depende do
   widget `TCCCoordinogramWidget` ter método `set_c_lines()` ou um
   override de `paintEvent`. v3.4.1 adicionará rendering matplotlib se
   o canvas não suportar nativamente.

3. **TCC Report extraction é heurística** — `_on_export_tcc_report` usa
   `getattr(c, "device_id", ...)` etc. para extrair fields. Devices
   reais com schemas custom podem precisar adapter.

4. **Multi-protection plot deferred** — Tutorial §Part 11 p.357-360
   (Phase + Ground simultâneos no mesmo TCC) não implementado nesta
   release. Adicionar como SKIPPED_BACKLOG D.1 (próximo doc update).
