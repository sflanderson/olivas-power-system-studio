## B. Fórmulas extraídas (anti-alucinação — todas com cit. literal)

### B.1 Asymmetrical Peak Fault Current — §1.2.3 p. 1-5 (linhas 312–316)

```
I_asym_peak = √2 · I_k · (1 + e^(-2πc/(X/R)))
```

- `I_k` = initial symm RMS fault current
- `c` = time in cycles (½ for momentary)
- Manual original mostra `e^{-2c/(X/R)}` — π **suprimido por pdftotext**;
  contexto físico (Eq. 7-1 §1.3.6) confirma `2π`

### B.2 Half-cycle Asymmetrical RMS — Phase A worst — §1.2.3 p. 1-6 (linhas 360–365, 410–414)

```
I_asym_rms_phaseA(½cyc) = I_symm_rms · √(1 + 2·e^(-2π/(X/R)))
```

Manual literal: `I_asym_rms 1/2 cycle = I_rms_symm · √(1 + 2·e^(-2π/(X/R)))` — Phase A worst-case.

### B.3 Half-cycle Asymmetrical RMS — average 3 phases — §1.2.3 p. 1-7 (linhas 420–424)

```
I_asym_rms_avg(½cyc) = I_symm_rms · √( (1/3) · ( (1 + 2·e^(-2π/(X/R)))² + 2·(1 + 0.5·e^(-2π/(X/R)))² ) )
```

Forma canônica IEEE/ANSI; manual escreve sem squares mas derivação requer `(...)²`.

### B.4 LV Duty Adjustment — §1.2.3 p. 1-6 (linhas 369–376)  ✅ JÁ EM v3.0.2

```
I_symm_LVF = I_symm_rms · √(1 + e^(-π/(X/R)_sys)) / √(1 + e^(-π/(X/R)_test))
```

### B.7 NACD Ratio — §1.3.7 p. 1-19/1-20 (validada empiricamente em 7 cases)

```
NACD = I_remote_total / I_total_at_fault
     = Σ(I_k de geradores REMOTE) / I_total_E/Z
```

Verificação contra exemplos:
- §1.3.7 BLDG 115: 3.796/6.330 = **0.5997** ✓ (manual cita "NACD RATIO: .5997")
- §1.4.3 Case 2 PROC A: 9.401/13.871 = **0.6778** ✓ (manual cita ".6778")
- §1.4.3 Case 1a: I_remote = 0 → NACD = 0.0000 ✓
- §1.4.3 Case 1b B5: I_remote = 5.290 = total → NACD = 1.0000 ✓
- §1.4.4 BLDG 115 SERV: 5.155/9.449 = **0.5456** ✓
- §1.4.4 025-MTR 25: I_remote/8.786 = **0.5410** ✓
- §1.4.4 026-TX G PRI: I_remote/8.558 = **0.5424** ✓

### B.8 NACD Modes — §1.3.3 p. 1-11 (linhas 620–636)

| Modo | Lógica | Curvas usadas |
|---|---|---|
| **ALL_REMOTE** | NACD := 1.0 forçado | Apenas dc-decay-only (Figs 1-3 / 1-12..1-15). MAIS CONSERVADOR. |
| **PREDOMINANT** | NACD ≥ 0.5 → REMOTE; NACD < 0.5 → LOCAL | Figs locais OU remotas (não interpola) |
| **INTERPOLATED** | Peso linear pela NACD | Combina LOCAL e REMOTE |

Manual nota explícita (linhas 632–635): **"Interpolated não é oficialmente reconhecido pelos ANSI C37 Standards"** — é interpretação técnica. Olivas pode oferecer com banner.

### B.9 Interpolation Formula (deduzida — §1.3.7 prose linhas 1147–1153)

```
MF_interp(X/R, NACD, cycle, fault) = NACD·MF_remote + (1−NACD)·MF_local
```

Validação no Case §1.4.3 Case 2 (NACD=0.6778):
- TOT5: All-Remote=1.030, Interpolated=1.020 → implica MF_local(11.88,5cyc) ≈ (1.020 − 0.6778×1.030)/0.3222 ≈ 1.0014 ✓
- TOT3: 1.093 vs 1.089 → MF_local ≈ 1.080 ✓
- TOT2: 1.257 vs 1.261 → MF_local ≈ 1.270 ✓ (curiosamente *maior* que Remote — coerente com ac-decay >> dc-decay para 2-ciclo)
