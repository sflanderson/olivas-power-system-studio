## Sprint B — Fix 2: Layout dos plots (constrained_layout + spacing)

### Princípio (do PTW manual)
Multi-curve em 1 viewport é o padrão preferido. Quando subplots empilhados
forem inevitáveis, usar matplotlib `constrained_layout=True` (handles
hspace adequado automaticamente).

### Mudanças

`ct_saturation_plots.py::plot_level3_dynamic`:
* Trocar `Figure(figsize=(9, 8))` → `Figure(figsize=(10, 9), constrained_layout=True)`
* Remover `fig.tight_layout()` no final (incompatível com constrained_layout)
* Subplot 2 título: trocar `set_title("Distorção da Forma de Onda")` por
  `set_ylabel("Corrente Sec. (A)\nDistorção da onda")` (label, não título)
* Subplot 1 e 2 com `set_xlabel("Tempo (ms)")` apenas no inferior

`ct_saturation_dialog.py`:
* Trocar `self.resize(1200, 850)` → `self.resize(1280, 900)`
* Form section: GroupBoxes com `setMaximumHeight(220)` para não esmagar
  o tab area
* Tab area com `stretch=2` (já tinha `stretch=1`) para priorizar plots

## Sprint C — Fix 3: Workflow exige seleção de TC

### Princípio (do PTW manual)
*"Available only when X is selected"* — itens acinzentados sem
prerequisito + right-click "Go To" no componente.

### Arquitetura

```
MainWindow
  ├─ menu "Análise > 🔍 Saturação de TC"
  │    └─ habilitado SOMENTE se selectedItem.component.type == "CT"
  │    └─ desabilitado: tooltip "Selecione um TC no canvas"
  │
  ├─ on_selection_changed() → atualiza enabled state da action
  │
  └─ _on_analyze_ct_saturation():
       ├─ obtém selected CT do scene
       ├─ se nenhum: QMessageBox.information "Selecione um TC"
       ├─ se ok: passa CTSelection ao dialog
       └─ dialog popula campos a partir de CTSelection
```

### CTSelection dataclass (helper)

```python
@dataclass(frozen=True)
class CTSelection:
    """Bridge entre PpComponent CT e CTSpec/CTFaultContext."""
    tag: str
    ratio_pri_A: float
    ratio_sec_A: float
    classe: str           # ANSI_C / IEC_P / IEC_PR
    c_rating_V: float
    rs_ohm: float
    rb_ohm: float
    kr: float
    t_relay_ms: float
    t_breaker_ms: float
    bus_id: str = ""      # vem de outro componente conectado (PR2)
    rated_voltage_kV: float = 13.8
    I_fault_rms_kA: float = 20.0
    X_over_R: float = 10.0

    @classmethod
    def from_pp_component(cls, comp) -> "CTSelection":
        """Constrói a partir de PpComponent type=CT."""
```

### Mudanças

`app/postprocessor/ct_saturation_io.py`:
* NEW `CTSelection` dataclass + `from_pp_component(comp)` classmethod

`app/gui/main_window.py`:
* `_on_analyze_ct_saturation`: detecta `scene.selectedItems()` antes de
  abrir dialog. Se vazio → QMessageBox + return.
* Conecta `scene.selectionChanged` → atualiza `act_ctsat.setEnabled()`

`app/gui/ct_saturation_dialog.py`:
* Construtor aceita `selection: CTSelection | None = None`
* Se `selection`, popula form a partir dela e bloqueia edição da TAG
  (read-only)
* Banner no topo: "🎯 Analisando TC '<tag>' do esquemático" (se
  selection) ou "📚 Modo didático (defaults)" (sem selection — só via
  ctrl+shift)

## Sprint D — Fix 4: Menu Gráficos com empty states + prerequisitos

### Princípio (do PTW manual)
Plot views nunca abrem vazias sem prerequisito. CAPTOR §1.2.1 lista
prerequisitos numerados. Datablock Reports mostram texto explicativo
quando vazios.

### Mudanças no menu

```
ANTES:
  Visualizar > Gráficos
    ├─ Voltage Profile (PF)        — abre dock vazio
    ├─ Source Contributions (SC)   — abre dock vazio
    ├─ TCC Coordination Curves     — abre dock vazio
    └─ Monte Carlo Histogram       — abre dock vazio

DEPOIS:
  Visualizar > Resultados (gráficos das análises)
    ├─ 📊 Perfil de Tensão (Power Flow) [Ctrl+Shift+1]
    │       └─ tooltip: "Disponível após Power Flow (F5 → PF)"
    ├─ 🥧 Contribuição das Fontes (Short-Circuit) [Ctrl+Shift+2]
    │       └─ tooltip: "Disponível após Curto-circuito (F5 → SC)"
    ├─ 📉 Curvas de Coordenação (TCC) [Ctrl+Shift+3]
    │       └─ tooltip: "Disponível após Coordenação (F5 → TCC)"
    └─ 🎲 Histograma Monte Carlo [Ctrl+Shift+4]
            └─ tooltip: "Disponível após Monte Carlo Reliability"
```

### Empty state no dock

Cada `PowerFlowVoltageProfileDock`, `ScContributionPieDock`, etc deve
ter um método `update_data(study_result)`. Quando o dock abre sem dados,
mostra um QLabel central (não matplotlib vazio):

```
┌──────────────────────────────────────┐
│  📊 Perfil de Tensão                 │
│                                      │
│  Esta janela mostra V/V_nom por      │
│  barramento após executar Power Flow │
│                                      │
│  Como popular:                       │
│  1. Pressione F5                     │
│  2. Marque "Power Flow"              │
│  3. Clique "Executar"                │
│                                      │
│  [▶ Executar agora]                  │
└──────────────────────────────────────┘
```
