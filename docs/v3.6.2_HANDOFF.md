## 3. Sprint D.1 — C-lines paint real

### Antes (v3.6.0)
`_on_c_lines_toggled` armazena curves em `_c_lines` attr; rendering
dependia do widget ter `set_c_lines()` que **não existia**. C-lines
button efetivamente no-op.

### Depois (v3.6.2)
NEW em `TCCCoordinogramWidget` (~50 LOC):
* `set_c_lines(c_lines)` — armazena lista + triggers _draw_all
* `get_c_lines()` — retorna cópia (anti-mutation)
* `_draw_c_lines(ax)` — renderiza dashed overlays color-coded:
  - Converte `points` (kA) → A (axis consistency com main coordinogram)
  - Label `"C: <IE> cal/cm² (PPE <cat>)"`
  - `linestyle="--"`, `alpha=0.8`, `zorder=5`
* `_draw_all` chama `_draw_c_lines` antes de `ax.legend()`

### Initial state
`__init__` agora inicializa `self._c_lines: list = []`.

## 4. Sprint D.2 — Multi-protection filter

### Antes (v3.6.0)
`TCCCoordinogramDialog` plotava todas curvas sem filtragem; sobrecarga
visual quando schema tinha Phase + Ground simultâneos.

### Depois (v3.6.2)
NEW em `TCCCoordinogramWidget`:
* `set_protection_filter(mode)` — modes `all`/`phase`/`ground`,
  validação de input
* `get_protection_filter()` — retorna estado
* `_curve_matches_protection(curve, mode)` (staticmethod) — heurística:
  - Inspeciona attrs `function`, `ansi`, `name`, `label`
  - Ground markers: `50n`, `51n`, `ground`, `neutral`, `terra`, `igoc`, `tgoc`
  - **Anti-data-loss**: curvas sem info SEMPRE exibidas
* `_draw_all` filtra por `_curve_matches_protection` antes de plotar

### UI
NEW em `TCCCoordinogramDialog.button_row`:
```
[Filtro:] [Combo: Todas / Phase (50/51) / Ground (50N/51N)]
```
Wired via `_on_protection_filter_changed` handler.

## 9. Anti-alucinação — limitações declaradas

1. **C-lines kA→A conversion assume points em kA** — `CLineCurve.points`
   da v3.4.0 são em kA por convenção NFPA 70E. Se outro módulo gerar
   pontos em A direto, plot ficará x1000 errado. Test
   `test_draw_c_lines_converts_ka_to_a` cobre o caso correto.

2. **Heurística de filtro Phase/Ground é por substring** — não usa
   schema estruturado. Falha em curvas com nome ambíguo (e.g.
   "Relé 50/50N misto"). Caso ambíguo: substring "50n" detectado →
   classificado como Ground (conservador para anti-data-loss).

3. **D.3 (3-tab pages) ainda aberto** — TCCCoordinogramDialog
   continua single-pane. Refatoração para QTabWidget (Settings /
   Curves / Datablock) deferred para v3.6.3 ou v3.7.x.

4. **C-lines não animáveis nem clicáveis** — apenas overlay estático.
   Click em C-line não abre dialog de detalhes; nem hover tooltip.
   Interactive C-lines deferred.
