### B+C — Calculator + Diversity (11 testes ✅)

Algorithm chunked multi-level (até 3 patamares):
- `apply_demand_levels(connected, levels)` retorna demand
- `compute_demand(entries)` agrupa, soma, aplica DF, multiplica LCL
- Diversity implícita via segundo/terceiro patamar (DF reduzido)

### D — UI dialog (7 testes ✅)

- QTableWidget de entries com 4 colunas (Nome / Categoria ComboBox /
  kVA SpinBox / PF override)

- 5 botões: Adicionar / Remover / ▶ Calcular (verde) / 💾 TXT / 💾 XLSX
- Banner explicativo + status via setWindowTitle (sem QMessageBox)

### E — TXT/XLSX export

## 5. User testing gate v1.5.1 (5 passos)

1. ✅ Olivas → Análise → ⚡ Demand Load Study (DAPPER...)

   (Iluminação 50 + Motor 75 + Tomadas 25 + Capacitor 100 + DC 30 kVA)

   weighted PF
4. ✅ Tab "Por Categoria" mostra 5 linhas (uma por categoria) com
   NEC section visível
5. ✅ Salvar TXT → abrir → verificar 4 seções (Resumo, Por Categoria,
   Detalhe, Citações Normativas) + valores

(NESC 2023, EPRI 2011, Doughty-Neal, DC Stokes, CSA-Z462).

  multi-level)
