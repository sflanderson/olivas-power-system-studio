## 4. Princípios de execução (idêntico a v1.3.1+)

1. **Cada sub-sprint começa com TDD** — testes canônicos antes do código.
2. **Cada plot tem teste de "não-crash"** com QImage + QPainter
   (idêntico ao padrão v1.4.3 BREAKER paint test).
3. **Cada plot tem pelo menos 1 teste estrutural** validando dados
   chave (cor da barra, presença do marcador joelho, etc.).
4. **GUI gate**: ao final, `_on_analyze` regenera as 4 tabs (Sumário +
   Plot N1 + Plot N2 + Plot N3) atomicamente.
5. **User testing gate**: smoke screenshot mental ao final — usuário
   abre Olivas → Pós-processamento → CT Saturation → vê 4 tabs com
   TC didático C400@2000:5 e julga se é equivalente ao MATLAB.
