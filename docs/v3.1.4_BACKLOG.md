## Razão do skip

v3.1.3 fechou os 4 wirings críticos do Editor PTW §Part 1 (context menu
Tags, link navigate, drop-on-wire, auto sidecar). Os 3 itens abaixo são
**refinamentos UX de qualidade** mas não bloqueiam a alpha pública —
foram conscientemente diferidos para que v3.2.0 (Component Editor
multipanel — Tier 1 fundacional) seja iniciado imediatamente.

Estes itens **DEVEM** voltar à fila antes de release v4.0.0 (paridade total).

---

## Deferred items

### 1. AddLinkTag dialog completo

**Estado atual** (v3.1.3): 2 `QInputDialog` simples — label + target.

**Refinement esperado**:
- Single dialog com:
  - Campo "Label exibido"
  - Combo de scheme (oneline / tcc / report / pdf)
  - Browser de targets (ex: list de TCCs do projeto, list de buses, file picker)
  - Color picker para cor do triangle (closed_arrow)
  - Toggle visible / closed_arrow
  - Preview live do tag

**Esforço**: M (2-3 dias)
**Trigger 7ª garantia**: já é acessível (v3.1.3); refinement = melhor UX

### 2. Multi-document navigation (`oneline:DocName`)

**Estado atual** (v3.1.3): scheme `oneline:` apenas mostra status message.

**Refinement esperado**:
- MainWindow mantém registry de documents abertos (já tem QTabWidget,
  mas o tab atual é genérico)
- Click em `oneline:DocName` Tag busca tab existente OU abre novo
- Per PTW Tutorial §Part 1 p.30-34 (Multiple one-lines compartilhando DB)

**Esforço**: L (3-5 dias) — mexe na arquitetura QTabWidget
**Trigger 7ª garantia**: feature parcialmente acessível (status msg ≠ navigate)

### 3. Wire path-based detection (em vez de bbox)

**Estado atual** (v3.1.3): `view._find_wire_at` usa busca bbox simples
com `tolerance=8.0`.

**Refinement esperado**:
- Detecção exata de intersecção com path L-routed do wire
- Distância perpendicular ao segmento (não bbox do bounding rect)
- Evita falsos positivos em wires longos diagonais

**Esforço**: S (1 dia)
**Trigger 7ª garantia**: feature acessível; refinement = correção UX
