## 8. Anti-alucinação — limitações declaradas

1. **Reliability é manual** — usuário insere eventos um a um. Auto-cálculo
   a partir de topologia (walker que enumera contingências) deferred
   v3.6.x.

2. **Sem persistência de eventos** — ao fechar dialog, eventos são
   perdidos. Save/load de reliability scenarios em sidecar JSON deferred.

3. **Series unavailability é first-order** — usa Σ q_i (small-q
   approx). Para q > 0.05, IEEE 493 §3.4.5 recomenda formula exata
   `1 - Π(1 - q_i)` — não implementada.

4. **MTTR/MTBF não usa Weibull** — assume distribuição exponencial.
   Análise por Weibull/lognormal deferred (PTW Reliability Module
   advanced).

5. **Sem Monte Carlo** — não simula time-series. Existing
   `arc_flash_monte_carlo.py` poderia ser estendido.
