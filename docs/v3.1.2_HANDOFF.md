### Sub-sprint B — Tag QGraphicsItems (8/24 ✅)

NEW `app/gui/schematic_pp/tag_items.py` (~250 LOC):

- **`LinkTagGraphicsItem`**: rounded-rect + texto + closed-arrow triangular
  - Click emite `link_clicked(target_uri)` para MainWindow tratar

**Reproduz** PTW Tutorial §Part 1 p.35-52.

### Sub-sprint C — AddSeriesComponentCommand (3/24 ✅)

`app/gui/schematic_pp/commands.py`:

- NEW `AddSeriesComponentCommand` (atômico — 1 redo / 1 undo)
- Inputs: scene, original_wire, new_component, wire_in, wire_out
- redo(): remove original wire + add component + add 2 new wires
- undo(): exato inverso
- Idempotente (redo/undo/redo preserva estado final)

**Reproduz** PTW Tutorial §Part 1 p.27 (auto-bus-node em série).

### Sub-sprint D — Sidecar JSON I/O (8/24 ✅)

NEW `app/gui/schematic_pp/sidecar_io.py` (~180 LOC):

- Format: `<project>.olivas.json` ao lado do `.sch` original
- Versionado (`olivas_version: 1`) para forward-compat
- Persiste:
  - `link_tags` (list)
  - `legend_tags` (list)
  - `linked_properties` (dict by component name → idx → library)
- API: `save_sidecar()` / `load_sidecar()` / `sidecar_path_for()`
- **Backward-compat**: skip-write se sem extensões; tolerant load
- Tests roundtrip completos

## 5. Smoke Test Manual

### 5.1 Library link gray-out (Sub-sprint A)
> 1. Abrir um BREAKER em property editor
> 2. Set `properties[1].linked_library = "ABB HD4"` no model
> 3. Re-abrir property editor → o campo `rated_voltage_kV` aparece **cinza** + botão 🔗
> 4. Clicar 🔗 → emite `unlink_requested(1)` → caller seta `linked_library = None`
> 5. Campo volta para editável

### 5.2 Tag QGraphicsItems (Sub-sprint B)
> 1. Em código, criar `PpLinkTag(label="Go A", target="oneline:DocA", x=100, y=100)`
> 2. Adicionar `LinkTagGraphicsItem(tag)` à scene
> 3. Aparece como caixa rounded com label + triangle indicator
> 4. Click → emite `link_clicked("oneline:DocA")`
>
> Para Legend:
> 1. `PpLegendTag(text="Zone HV", shape="Diamond")`
> 2. `LegendTagGraphicsItem(tag)` desenha diamante 36×36 amarelo PTW
> 3. Shape pode ser trocada para Hexagon / Circle / Rectangle

### 5.3 Auto-bus-node em série (Sub-sprint C)
> 1. Tem um wire de (0,0) → (200,0)
> 2. Cria `AddSeriesComponentCommand(scene, original_wire, R_component, wire_in, wire_out)`
> 3. `cmd.redo()` → wire original some, R aparece em (100,0), 2 novos wires conectam
> 4. `Ctrl+Z` (undo) → tudo volta como era

### 5.4 Sidecar JSON (Sub-sprint D)
> 1. Salvar `.sch` com link_tags ou legend_tags ou linked properties
> 2. `save_sidecar(project, "myproject.sch")` cria `myproject.olivas.json`
> 3. `load_sidecar(project, "myproject.sch")` repopula extensions
