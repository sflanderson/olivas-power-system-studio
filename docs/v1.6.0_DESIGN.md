## 3. Sprint B — Doughty-Neal-Floyd 2000

### 3.1 API contract

```python
# app/standards/doughty_neal_arc_flash.py

def doughty_neal_open_air_cal_cm2(
    Ia_kA: float,
    arc_clearing_time_s: float,
    distance_mm: float,
) -> float:
    """
    E_MA = 5271 · D^(-1.4738) · t · (0.0016·Ia² - 0.0076·Ia + 0.8938)

    Reference: IEEE 1584-2002 Annex B reproduz Doughty-Neal-Floyd.
    Range: V_oc ≤ 600 V, Ia em kA (range 16–50 kA), D em mm
    (D < 455 mm).
    """


def doughty_neal_in_box_cal_cm2(
    Ia_kA: float, arc_clearing_time_s: float, distance_mm: float,
) -> float:
    """
    E_MB = 1038.7 · D^(-1.4738) · t · (0.0093·Ia² - 0.3453·Ia + 5.9675)
    """
```

### 3.2 Golden values (do paper original / IEEE 1584-2002 Annex B)

* IEEE 1584-2002 Annex B Example: Ia=20kA, t=0.5s, D=455mm
  → E_MA ≈ 0.6 cal/cm² (open air)
* Mesma config in box: D=610mm → E_MB ≈ ~3 cal/cm²

(Se valores específicos não forem reproducíveis, **marcar teste com
`@pytest.mark.skip(reason="no golden value available")`** ao invés de
inventar — anti-alucinação.)

## 4. Sprint C — DC arc flash

### 4.1 API contract

```python
# app/standards/dc_arc_flash.py

@dataclass(frozen=True)
class DCArcFlashResult:
    incident_energy_cal_cm2: float
    incident_energy_J_per_cm2: float
    arc_flash_boundary_mm: float
    arc_voltage_V: float
    arc_current_A: float
    method: str = "NFPA 70E §D.5 max-power"


def dc_arc_flash_max_power(
    V_system: float,
    I_short_circuit_A: float,
    arc_clearing_time_s: float,
    working_distance_mm: float = 457.0,   # 18 in default
) -> DCArcFlashResult:
    """
    NFPA 70E:2024 Annex D.5 método de potência máxima:

    V_arc = V_sys / 2     (max power transfer)
    I_arc = I_sc / 2
    P_max = V_arc · I_arc = V_sys · I_sc / 4
    E (cal/cm²) = (P_max · t) / (4π · D² · 6.7)
    """
```

### 4.2 Golden values

* Exemplo NFPA 70E §D.5 Table D.5.2(a):
  V=125V, Isc=2500A, t=0.5s, D=457mm → E ≈ ~ 4.4 cal/cm²
  (Se exemplo não for reproducível literalmente, usar physics
  sanity + ratio testing.)

   DC method aparece com energia
