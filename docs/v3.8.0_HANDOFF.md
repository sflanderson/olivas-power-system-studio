## 3. Sprint v3.7.1 — Branch impedance extraction (B.1)

NEW `app/postprocessor/branch_impedance.py` (~250 LOC):

* **Constants**: `RHO_CU_OHM_MM2_PER_M = 1/56`, `RHO_AL = 1/35` (IEC 60364)
* **`BranchImpedance` dataclass** — R_pu, X_pu, B_pu, source
* **`transformer_impedance_pu(component, base_MVA)`** — IEC 60076-1 §10:
  - Z_pu_xfmr = v_sc_pct/100
  - R from p_sc_kW; senão X/R≈7 heuristic
  - Convert to system base via S_base/S_nom ratio
* **`cable_impedance_pu(component, base_MVA, voltage_base_kV)`** — IEC 60364:
  - R = ρ × L / section
  - X ≈ 0.08 Ω/km typical for LV in conduit
* **`tline_impedance_pu`** — usa R_per_km × length; X = 5×R (typical aerial)
* **`extract_branch_impedance`** — dispatch by `component.type`

`build_pf_system_from_project` agora **encontra branch component** próximo
ao midpoint Manhattan dos buses adjacentes; usa `extract_branch_impedance`.
Fallback default (R=0.01, X=0.05) apenas quando não há branch component.

## 5. Sprint v3.8.0 — Reliability Monte Carlo (major)

NEW `app/postprocessor/reliability_monte_carlo.py` (~280 LOC):

### Library presets IEEE 493-2007 Tab 3-1
**10 equipment types** com MTBF/MTTR típicos:
- transformer_liquid_filled / transformer_dry_type
- circuit_breaker_metalclad / circuit_breaker_lv
- cable_underground_lv / cable_aerial_mv
- induction_motor_400hp
- switchgear_lv / ups_battery / generator_diesel

API: `list_preset_types()`, `get_preset(type)`, `make_component_from_preset(name, type)`.

### Time-series Monte Carlo
`run_monte_carlo(components, n_years, n_simulations, seed) → MCResult`

Para cada simulação:
1. Para cada componente, sample failure times via **exponencial**
   (rate λ = 1/MTBF)
2. Sample MTTR via **lognormal** (mean=MTTR, σ configurável)
3. Compute SAIFI/SAIDI/CAIDI/ASAI via `calculate_indices`

`MCResult`:
- `percentile(dist, p)` — interpolação linear
- `confidence_interval(dist, alpha=0.10)` — 90% CI default
- `mean(dist)`, `median(dist)`
- `as_text_report()` — formato pt-BR

### GUI
Botão "🎲 Monte Carlo (IEEE 493 presets)" no `ReliabilityDialog`
button row. Roda exemplo 5-component (T+2BR+CBL+M) × 10 anos × 100 sims
com seed=42.

**Tests**: 18 verdes (`test_pp_v3_8_0_reliability_mc.py`).

## 10. Anti-alucinação — limitações declaradas

### v3.7.1 B.1
1. Cable X = 0.08 Ω/km hardcoded (típico LV conduit). HV cables com
   spacing geométrico têm X muito diferente — deferred.
2. Transformer X/R = 7 heuristic when p_sc_kW ausente.
3. Branch midpoint Manhattan é heurística — projetos com topologia
   cruzada podem matchear branch errado. Wire-path-based assignment
   deferred.

### v3.7.2 C.1
1. PowerFlowDialog NÃO removido — apenas deprecated. Removal v4.0.0
   ainda exige cleanup de callers.

### v3.7.2 C.2
1. Hybrid mode mistura demos com project no mesmo report; UI não
   distingue visualmente quem é quem (deferred coloring).

### v3.8.0 Reliability MC
1. Independent failures only — no common-cause / common-mode.
2. Lognormal MTTR shape σ=0.5 hardcoded (configurável via param mas
   default pode não match reality).
3. Customers per component fixo — não modela impacto topology.
