## Validação por issue (com evidência forense)

### Issue #1 — ATP residual no chat (🔴 P0 — REGRESSÃO)

**Sintoma reportado**: comando `executar / run — rodar simulação ATP`, `abrir <caminho>` (.atp).

**Evidência**:
```
app/gui/chat_widget.py:183:  executar / run          — rodar simulação ATP
app/gui/chat_widget.py:189:  abrir <caminho>         — abrir arquivo .atp
app/gui/chat_widget.py:190:  salvar <caminho>        — salvar arquivo .atp
app/gui/chat_widget.py:381:  "Abra um arquivo .atp para comecar."
app/gui/main_window.py:1244: status.showMessage("Pronto — abra um arquivo .atp para começar.")
```

**Análise**: regressão do reposicionamento v0.92.2 ("Olivas ATP Studio" → "Olivas Power System Studio"). Strings `chat_widget.py` e `main_window.py:1244` ficaram orfãs.

**Fix v1.4.1**:
- Substituir mensagens ATP no chat por equivalentes orientados a análise elétrica:
  - "rodar simulação ATP" → REMOVER (delegar para menu Análise)
  - "abrir/salvar .atp" → "abrir/salvar .opws / .sch"
  - "Abra um arquivo .atp" → "Abra um esquemático .sch"
- Atualizar status bar: "Pronto — abra um esquemático .sch ou crie um novo."

### Issue #2 — Logo Olivas no app icon (🟡 P1)

**Sintoma reportado**: "Icone do software não aparece a logo do olivas"

**Evidência**:
```
app/resources/logo.png : exists, 96149 bytes
app/main.py:34: app.setWindowIcon(icon)  ← aplicado
app/main.py:62: window.setWindowIcon(QIcon(...))  ← aplicado
```

**Análise**: logo está sendo aplicado, mas ícone na barra de título do screenshot mostra "O" genérico.
Hipóteses:
1. `logo.png` é grande (96KB) mas pode não ter as resoluções 16/32/48px que Windows usa para title bar
2. PNG sem alpha channel ou com fundo branco fica esmaecido em title bar dark

**Fix v1.4.1**: gerar `logo.ico` multi-resolução (16/32/48/64px) + `setWindowIcon` em todas as QDialog spawned.

### Issue #6 — Trafo trifásico sem config de enrolamento (🔴 P0)

**Sintoma reportado**: "Atualmente não existem transformadores trifásicos com seleção de enrolamento delta-estrela; estrela-delta; delta-estrela aterrado (com e sem impedância); estrela-estrela; e sem possibilidade de determinar a impedância do transformador"

**Evidência** (`Tr3.ocomp`):
- Tem `ratio` (string)
- Tem `L_mag` (magnetização)
- Tem campos BCTRAN (V_H, V_M, V_B, S_H, v_sc_HM_pct...) — orientados ATP simulação
- **NÃO tem campo de configuração** (vector_group: Dyn1, Yd1, Yyn0, Dyn5, etc.)
- **NÃO tem campo `impedance_pct`** padrão ANSI direto

**Fix v1.4.1**: criar novo `XFMR3.ocomp` (transformador trifásico para análise — não-ATP) com:
- `vector_group`: enum Yyn0, Dyn1, Yd1, Yd11, Dy1, Dy11, Dyn5, YNyn0, etc.
- `kVA_rated`, `V_pri_kV`, `V_sec_kV`
- `impedance_pct` (ex 5.75% típico)
- `xr_ratio` (X/R, ex 6 típico LV)
- `tap_position` (5 taps padrão ±2.5%)
- `winding_grounding_pri` / `winding_grounding_sec` (None / Solid / Resistance)
- `grounding_resistance_ohm` (se Resistance)
- `connection_phase_shift` (Yd11 = 30° lag, etc., calculado auto)

### Issue #9 — RELAY ausente da paleta (🔴 P0)

**Sintoma reportado**: "Não existe relé na paleta de componentes"

**Evidência** (paleta atual em screenshot):
- Categoria "🛡️ Proteção": CONTACTOR, CT, FUSE, **Relais**, SwIdeal, SwTACS, VCB, VCB3
- "Relais" = "Chave controlada" (NÃO é relé de proteção 50/51 — é uma chave)
- Nenhum componente com função 50/51/87 nativa

**Fix v1.4.1**: criar `RELAY.ocomp` (componente novo, distinto de Relais):
- `code`: RELAY
- `label_pt`: "Relé de proteção (50/51/49/87)"
- `category`: switch
- 4 pinos: P1/P2 (loop principal — passa em série) + Trip out + Common
- Properties:
  - `tag` (ex "R-MAIN-1")
  - `vendor_model` (string — link para library)
  - `ansi_devices` (multiselect: 50/51/50N/51N/49/87/27/59/79/81)
  - `pickup_51_A`, `tms_51`, `curve_51` (enum)
  - `pickup_50_A`, `delay_50_s`
  - `pickup_49_A`, `delay_49_s`
  - `pickup_87_A`, `delay_87_s`
- Renderer: PTW-style (similar a Relais mas com bobina + retângulo)
