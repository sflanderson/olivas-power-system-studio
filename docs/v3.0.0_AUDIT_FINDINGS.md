## Audit 2 — PTW Comparison Matrix

### Matriz 19 itens (resumo)

**Olivas SUPERIOR a PTW em**:
- A6 Arc-flash multi-standard (8 standards vs 1 IEEE 1584 do PTW)
- A10 CT Saturation (3 níveis ANSI/IEC/dynamic — PTW não tem dedicado)
- A11 DC Arc-flash (NFPA 70E §D.5 — PTW não tem)
- B3 Custom plugins (Olivas tem Marketplace; PTW closed-source)
- C1/C2 IEC 61850 MMS+GOOSE+SV+BER (PTW não menciona)
- C4 Multi-language PT/EN/ES (PTW só EN)
- D1 Docker reproducibility (PTW = Windows + FlexLM)
- D2 Open-source + commercial dual model

**PTW SUPERIOR a Olivas em**:
- A3 ANSI legacy short-circuit (NACD, Test PF/X/R por device class C37.13/.010)
- A4 CAPTOR coordination (17 segment types vs 9; multi-function relay; damage curves)
- B1 Equipment Library hierárquica (~80-100 itens vendor)
- B2 Equipment Evaluation Dashboard unificado (9 critérios pass/fail color-coded)

### Veredicto comercial honesto

> **Olivas v3.0.0 substitui PTW para**:
> - Projetos brasileiros (NBR 17227, NR-10, NBR 5410)
> - Trabalhos acadêmicos
> - Sistemas DC/BESS/PV (arc-flash superior)
> - Integrações SCADA IEC 61850
>
> **Olivas v3.0.0 NÃO substitui PTW para**:
> - Coordenação TCC heavy-duty com relés multi-função (CAPTOR-grade)
> - Compliance ANSI C37 strict (US legacy)
> - Bibliotecas vendor extensas com hierarquia profunda
>
> **Path para paridade comercial**: backlog v1.2 (P0) tinha
> Custom Label Designer, 17 TCC segments, multi-function relay,
> Coordination Rule Engine, Equipment Eval Dashboard. Esses
> ainda estão pendentes em v3.0.0 — fica para v3.1+.

### Limitação metodológica declarada

PDFs PTW não foram lidos byte-a-byte (sem `pdftoppm`). Evidência
veio de: (a) inventário filenames, (b) audit v1.1.0 com seções
citadas, (c) handoffs Olivas com comparações side-by-side.
