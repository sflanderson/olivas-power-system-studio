## 3. Sprint A.3 — Wire path-based detection

### Mudança técnica

NEW em `app/gui/schematic_pp/view.py` (linhas 797-842):

```python
def _point_to_segment_distance(px, py, ax, ay, bx, by) -> float:
    """Standard projection com clamp t∈[0,1]."""
    ...

def _point_to_l_route_distance(px, py, x1, y1, x2, y2) -> float:
    """L-route: h-segment depois v-segment (mirrors WireItem.paint)."""
    if x1 == x2 or y1 == y2:
        return _point_to_segment_distance(px, py, x1, y1, x2, y2)
    d1 = _point_to_segment_distance(px, py, x1, y1, x2, y1)
    d2 = _point_to_segment_distance(px, py, x2, y1, x2, y2)
    return min(d1, d2)
```

MODIFICADO `_find_wire_at` (L300-340):
- **Antes** (v3.5.0): bbox check `wire_item.boundingRect().contains(pt)`
  — falsos positivos quando ponto está na "diagonal" do bounding box
  mas longe do path real
- **Depois** (v3.5.1):
  1. Fast filter: bbox search `tolerance × 4` para reduzir candidatos
  2. Para cada candidato: `_point_to_l_route_distance(...)`
  3. Aceita apenas se `dist <= tolerance` (default 8.0px)

### Anti-falso-positivo crítico

Caso wire (0,0)→(100,100) com L-route via (100,0):

| P | Bbox antigo | Distance nova |
|---|-------------|---------------|
| (50, 50) | DETECTA (FP) | **80** (correto, longe do path) |
| (50, 0) | DETECTA | **0** (no h-segment) |
| (100, 50) | DETECTA | **0** (no v-segment) |
| (50, 5) | DETECTA | **5** (dentro tolerance) |
