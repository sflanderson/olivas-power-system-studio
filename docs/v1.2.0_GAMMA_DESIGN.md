# v1.2.0 Fase γ — Design Document (Damage Curves)

**Sprint**: γ (Damage Curves Overlay)
**Plano pai**: `docs/v1.2.0_EXECUTION_PLAN.md`
**Pré-requisito**: Fases α (16 segments) + β (devices) concluídas + audit limpo
**Princípio**: documentar decisão de design ANTES de codar; cada fórmula vem de norma identificada e citada.

---

## Problema

Em coordenação real (IEEE 242 §15), as curvas de **proteção** (51, 50, 49, 87) precisam estar **abaixo** das curvas de **damage** dos equipamentos protegidos:

* **Cable damage** — se a corrente exceder o limite térmico do isolamento (`I²·t > K²·S²`), o cabo derrete antes do relé operar — perda total
* **Transformer through-fault** — se a curva de proteção cruza a curva ANSI de through-fault (IEEE C57.109), o transformador acumula stress térmico/mecânico irreversível
* **Motor thermal limit** — se o relé 49 não disparar antes do `locked rotor heating curve`, o motor queima

PTW CAPTOR plota essas damage curves **automaticamente** sobreposto às proteções (cor vermelha, tracejado), e marca violation se há cruzamento.

Olivas v1.2.0 α+β tem segments de proteção mas **NÃO tem damage curves**. Esta é a Fase γ.

## Solução: módulo `tcc_damage.py` paralelo

### γ.1 — Cable damage curve (NBR 5410 §6.5.4)

Fórmula da norma:

```
t_damage = (K · S)² / I²            [s]
```

onde:
- `S` = seção do cabo em mm²
- `I` = corrente em A
- `K` = constante de material/isolação (Tabela 43 NBR 5410):
  - Cu / PVC ≤300 mm² → K = 115
  - Cu / PVC >300 mm² → K = 103
  - Cu / EPR ou XLPE → K = 143
  - Al / PVC → K = 76
  - Al / EPR ou XLPE → K = 94

Implementação proposta:

```python
class CableMaterial(str, Enum):
    Cu_PVC = "Cu/PVC"
    Cu_XLPE = "Cu/XLPE"
    Cu_EPR = "Cu/EPR"
    Al_PVC = "Al/PVC"
    Al_XLPE = "Al/XLPE"

@dataclass(frozen=True)
class CableDamageCurve:
    cable_id: str
    section_mm2: float
    material: CableMaterial
    enabled: bool = True

    def damage_time_at_current(self, I_A: float) -> float:
        """t = (K·S)² / I² conforme NBR 5410 §6.5.4."""

    def damage_points(...) -> list[tuple[float, float]]:
        ...
```

**Por que NÃO subclass de TCCSegment**: damage curve é "limite a evitar", não "característica de proteção". Conceptualmente diferente — ainda que a fórmula seja `t(I)`, o uso é como overlay vermelho, não como elemento ativo.

### γ.2 — Transformer through-fault (IEEE C57.109)

IEEE C57.109-1993 categoriza transformadores em 4 categorias por kVA:

| Categoria | kVA range (1ph) | kVA range (3ph) | Curve type |
|---|---|---|---|
| I | 5–500 | 15–500 | Frequent faults |
| II | 501–1667 | 501–5000 | Frequent faults |
| III | 1668–10000 | 5001–30000 | Infrequent faults |
| IV | >10000 | >30000 | Infrequent faults |

Cada categoria tem uma curva tabulada (pontos I/In × t):

**Cat I** (frequent faults pattern, mais conservador):
- 25× In = 2 s
- 20× In = 3 s
- 16.6× In = 6 s
- 14.3× In = 9 s
- 12.5× In = 12 s
- 11.1× In = 16 s
- 10× In = 20 s
- 9× In = 25 s
- 8× In = 30 s
- 7× In = 40 s
- 6× In = 50 s

**Cat II/III/IV**: variantes da Cat I com inflexões em diferentes pontos (tabuladas).

Implementação proposta:

```python
class XfmrCategory(str, Enum):
    CAT_I = "Cat I (5-500 kVA)"
    CAT_II = "Cat II (501-5000 kVA)"
    CAT_III = "Cat III (5001-30000 kVA)"
    CAT_IV = "Cat IV (>30000 kVA)"

@dataclass(frozen=True)
class TransformerThroughFaultCurve:
    xfmr_id: str
    rated_current_A: float
    category: XfmrCategory
    enabled: bool = True

    def through_fault_time_at_current(self, I_A: float) -> float:
        """Interpolação log-log entre pontos tabulados IEEE C57.109."""
```

Pontos tabulados ficam em dict const `_XFMR_THROUGH_FAULT_POINTS_BY_CATEGORY` — anti-alucinação: pontos vêm DIRETO da Tabela 1 / Figura 1 de IEEE C57.109-1993.

### γ.3 — Motor thermal limit (IEC 60079-7 / NEMA MG-1)

IEC 60079-7 (motors for explosive atmospheres) define `locked rotor time` (`tE`) — tempo até a temperatura crítica:

```
t_thermal(I) = K_motor · (I_LR / I)²    para I > 1.05·In
```

Modelagem simplificada:
- Para `I` no range de starting (1.5–6× FLA): `t = motor_starting_time` (típico 10s para acelerar carga)
- Para `I = locked rotor (LR ~6× FLA)`: `t = tE` (tempo locked rotor permitido)
- Acima: queda I²-inversa

Implementação proposta:

```python
@dataclass(frozen=True)
class MotorThermalCurve:
    motor_id: str
    fla_A: float                # full load amps
    locked_rotor_factor: float = 6.0   # I_LR / I_FLA
    locked_rotor_time_s: float = 10.0  # tE da norma (depende do motor)
    enabled: bool = True

    def thermal_time_at_current(self, I_A: float) -> float:
        """Curva característica thermal do motor (IEC 60079-7 / NEMA MG-1)."""
```

**Limitação documentada**: para precisão de datasheet específico, usar `TCCSegmentTimeCurrentPoints` com tabela do fabricante. Esta classe é o modelo analítico padrão (NEMA MG-1 §12.45).

## Riscos antecipados

| Risco | Mitigação |
|---|---|
| Hardcoding de pontos IEEE C57.109 sem fonte | Referência explícita: "Tabela 1 IEEE C57.109-1993" + comentário com cada ponto |
| Confusão entre damage curve e protection segment | Naming explícito: `*DamageCurve` (não `*Segment`) |
| Reusar TCCSegmentTimeCurrentPoints cria dependency invertida | NÃO reusar — duplicar lógica de interpolação se necessário |
| K material errado por confusão de tabela | Tests canônicos: `Cu/PVC ≤300mm² = 115`, etc. — comparado com NBR direto |
| Interpolação log-log fora do range falha silenciosa | Edge case explícito: abaixo do menor I retorna inf, acima do maior extrapola conservador (slope dos 2 últimos) |
| Motor thermal model muito simplificado | Documentar limitação clara: "use TimeCurrentPoints com datasheet para precisão" |

## Glossário (anti-confusão)

| Termo | Significado |
|---|---|
| **Damage curve** | Curva limite de equipamento (não deve ser cruzada por proteção) |
| **Through-fault** | Fault que passa por um transformador (curva IEEE C57.109) |
| **Locked rotor (LR)** | Motor com rotor parado mas energizado — corrente alta |
| **tE** | Tempo locked rotor permitido (IEC 60079-7) |
| **K_cable** | Constante térmica do isolamento (Tabela 43 NBR 5410) |
| **TCCDevice** | Dispositivo de proteção (Fase β) |
| **TCCSegment** | Atomic curve element (Fase α) |
| **\*DamageCurve** | Limite de equipamento (Fase γ — esta) |
