## 1. Resumo

v2.0.0 entregou IEC 61850 **MMS** client (read-only de medições).
v2.2.0 adiciona os outros 2 protocolos do IEC 61850-8-1/9-2:

* **GOOSE** (Generic Object Oriented Substation Event) — comunicação
  time-critical para trip/interlocking entre IEDs
* **SV** (Sample Values) — streaming high-bandwidth de medições
  amostradas (V/I de Merging Units)

Ambos em **stub mode funcional** (lógica de protocolo válida)
para demo/testes; real mode delega para libiec61850 (não bundled).
