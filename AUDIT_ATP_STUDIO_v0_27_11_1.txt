4. PRIORIDADES P1 — BLOQUEIO DE PRODUÇÃO
================================================================

P1.1 [bus_pipeline.py] DEFAULTS CONSERVADORES MASCARAM
SUBDIMENSIONAMENTO:
- default_utility_S_kQ_MVA = 500 MVA (concessionária real
  forte tem 2000-5000 MVA → subestima Ik'').
- transformer_default_uk_pct = 10% (TRs reais 4-6% →
  subestima Ik'').
- S_MVA = 25 hardcoded para Tr/sTr (linha 636) — sem
  parsing real do schema.

Ação: warnings críticos quando defaults usados; warning
forte se nenhum dado real disponível.

P1.2 [bus_pipeline.py] comp.name[:6] trunca silenciosamente
em múltiplos pontos (linhas 437, 454, 516, 661):
- Colisão de nomes possível.
- Perda de auditabilidade.
- Tracking back ao componente fonte fica ambíguo.

Ação: usar UUID interno ou hash; warning se truncado.

P1.3 [iec60909.py] Decay μ·q (near-to-generator) AUSENTE:
- Ib = Ik = Ik'' sempre (linha 531-532).
- Para faltas próximas a SM grande, Ib real é 60-80% de
  Ik'' → SOBRESTIMA breaking duty → equipamentos podem ser
  oversized (custo) ou tripping spurious.
- Far-from-generator é default sem detecção automática.

Ação: implementar §4.5/4.6 da IEC 60909-0 (μ-fator para
decaimento do Xd' subtransient ao Xd' transient e q-fator
para gerador assíncrono).

P1.4 [iec60909.py] Method C (frequency-equivalent) AUSENTE:
- Apenas Method B implementado.
- Para malhas com R/X variáveis, Method B sobrestima ip
  até 30% (cf. IEC TR 60909-1).

Ação: implementar Method C antes de uso em sistemas
malhados industriais grandes.

P1.5 [iec60909.py] Sequencial 0/1/2 AUSENTE:
- Faltas LG/LL/LLG não suportadas.
- Crítico para 50N/51N (proteção de terra).
- Limitação compartilhada com short_circuit.py.

Ação: implementar Z_0 e Z_2 para SM, TR, linha (já
existe Xd_0, X0 no schema do SM!).

7. FRAGILIDADES CROSS-CUTTING
================================================================

7.1 DEFAULTS QUE MASCARAM SUBDIMENSIONAMENTO
   S_kQ=500 MVA, uk=10%, S_TR=25 MVA, Xd''=0.20, locked
   rotor=6× — todos espalhados sem fonte normativa única.
   Recomendação: classe DefaultsRegistry centralizada com
   fonte normativa explícita por defaults.

7.2 SILENT FALLBACKS
   - HCB/VOA/HOA → VCB (nbr17227)
   - Tipos não suportados → ignored (multihop_walker linha 456)
   - equipment_class faltante → KeyError (arc_flash)
   Recomendação: warnings estruturados sempre que fallback usado.

7.3 HEURÍSTICAS HARDCODED SEM FLAG
   - R/X 90% indutivo (motor_starting)
   - Tipo de carga (motor_starting)
   - Lado HV/LV de TR (multihop_walker)
   - 0.95 × ωs como velocidade alvo (motor_starting)
   Recomendação: cada uma com parâmetro override no Case.

7.4 MAGIC NUMBERS SEM SOURCE
   Linhas espalhadas: 6.23 (K_base nbr17227), 0.10 (R/X),
   1e9 (Z para fonte ignorada), 0.05 (time_for_idc_s).
   Recomendação: const named no topo + docstring com IEC §.

7.5 INCONSISTÊNCIAS REGISTRY vs SOLVER
   - TMS range Schneider vs IEC.
   - relay_model.application vs application calculada.
   Recomendação: testes cruzados em test_pp_registry_guard.
